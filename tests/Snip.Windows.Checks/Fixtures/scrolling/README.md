# 网页回归样例

这些文件都是公开、固定的本地测试数据，无需登录和网络服务。Chrome 集成检查直接使用这些文件，也可手动用 Chrome/Edge 打开后测试软件。

| 文件 | 验证内容 |
| --- | --- |
| colored-rows.html | 50 行、3650 CSS 像素高；整页、可见页、选定区域三个入口 |
| article-fixed-footer.html | 8 个白底图文段落、4320 CSS 像素高、固定底部栏；每段一个唯一颜色标记，检查无丢段/重复，并检查软件自身置顶窗口的隐藏与恢复 |
| short-page.html | 内容不足一屏，整页捕捉不能误报无法滚动 |

自动检查当前使用 CI 的默认页面缩放和单显示器。多屏 100%/150% 混合 DPI、网页 80%/125% 缩放、嵌套滚动容器和动态布局仍需另外验收，不将它们算作当前自动检查通过的场景。
