# 2.0.14 接入唯一 Hy-MT2 离线翻译模型

用户确认使用 Hy-MT2-1.8B Q3_K_M，且只要一个离线模型。本轮替换旧 OPUS/ONNX 后端，中英两个方向共享同一 GGUF 文件，保留已经存在的 DeepSeek/通义千问在线功能。没有模型选择或旧模型回退。

## 使用

退出旧版托盘后运行新 Snip.exe，在文字工作台点击“下载 / 修复模型”。首次下载约 951 MB 模型和约 20 MB 官方 CPU 推理器，总下载约 971 MB；不需要 Python、Ollama 或自行部署服务。下载并校验一次后可断网翻译。

Windows 需要微软 Visual C++ x64 运行库。缺少时面板显示官方下载安装入口，启动前明确提示；不把依赖缺失误报为重新下载模型即可解决。首次安装微软运行库由用户在官方安装程序中完成，不自动发起系统安装。

旧 OPUS 文件不会自动删除，但不再用于推理。在线密钥和自定义快捷键配置继续使用。新模型保存在 `%LOCALAPPDATA%\SelfSnip\Models\Hy-MT2-1.8B`。确认新版可用后，可以自行删除旧 Models 下的 en-zh、zh-en 子目录以释放磁盘。

默认 CPU 两线程，翻译时才加载。完成、取消、失败或关闭窗口后回收工作进程；Windows 用 Job Object 在主程序意外退出时关闭工作进程树。任务串行，避免多个结果窗口同时加载多份模型。OCR 原文仍可修改，截图和在线服务设置不变。

## 已知边界

官方原模型评分不能当作 Q3 文件评分，也不能保证专业长文达到在线大模型水平。OCR 漏识别仍需先修正原文。当前单次原文最多 12000 字符；过长段落按边界分段，实际分词超上下文或译文到生成上限会提示缩短原文，保留之前结果。

首次下载需网络，之后离线推理只访问本机回环；不上传原文/截图。下载源为固定 Hugging Face 模型版本和官方 GitHub 运行库。Windows x64 是交付目标；Linux CPU 用于开发验证，不能代替 Windows 桌面验收。
