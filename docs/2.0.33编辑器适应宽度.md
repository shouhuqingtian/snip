# 2.0.33：编辑器适应宽度

用户希望长截图能够按编辑窗口宽度铺开，避免“适应窗口”把整张长图缩小后文字难以阅读。本轮增加独立的“适应宽度”，默认打开仍使用“适应窗口”。

## 使用

- 编辑器右下角新增“适应宽度”：整张图片保持比例铺满内容区宽度，长图通过滚轮或右侧滚动条上下查看。自动计算时使用扣除边距和滚动条后的实际内容宽度。
- 拖动窗口大小时，宽度模式自动重新计算。该模式预留纵向滚动条位置，避免临界尺寸下滚动条出现/消失导致画面反复缩放。
- “适应窗口”保留，按宽高同时显示完整图片；超长图可自动低于原来的 10% 下限。适应宽度允许小图放大、宽图缩小，不会拉伸变形。
- 点击加减按钮进入手动缩放，后续改变窗口大小保留手动比例；再次点击任一适应按钮恢复对应自动模式。普通手动缩放范围扩展到 0.1%～1600%，自动适应的极端比例切换手动时避免反方向跳变。
- 当前模式的按钮显示强调色。缩放只影响查看，截图、标注和导出 PNG 保持原始像素尺寸；不重采样保存，也不重新采集网页。
- 模式仅作用于当前编辑窗口，没有新增全局默认或磁盘设置。
