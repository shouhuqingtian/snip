# 2.0.10 OCR 语言与小图空结果修复

用户截图显示：识别语言 zh-Hans-CN、内容只有 ChatGPT、状态“没有识别到文字”、原文和译文为空。结果窗口正常显示，属于 OCR 空结果，翻译尚未启动。原始截图 PNG 未提供，不把面板预览放大后的字形当作原始图片像素尺寸。

## 已确认的代码问题与处理

之前默认选择中文组件，空结果后直接停止；没有自动尝试英语，也没有处理短边很小、紧贴字形的区域截图。中文 Windows OCR 有时能识别拉丁字母，不能仅凭中文选项认定它完全不识别英文。修复不硬编码 ChatGPT，也不接入在线服务。

## 修改文件

- `src/Snip.Core/OcrLanguageSelection.cs`：自动中英候选选择，最多两个已安装语言，显式选择保持原样，支持其他手动语言。
- `src/Snip.App/ViewModels/TextResultViewModel.cs`：默认“自动（中英）”；空结果尝试下一候选；成功显示实际语言并继续原翻译流程；缺少英语组件和手动空结果均有可操作提示。记录语言/计数，不记录识别文本。
- `src/Snip.App/Views/TextResultWindow.xaml`：识别语言下拉框适配自动模式标签。
- `src/Snip.Infrastructure/OfflineOcrService.cs`：保留原分块识别；首次空结果且短边小于 64、原图至多 25 万像素时，2～4 倍放大、16 像素留白后重试一次，处理图片至多 200 万像素，结果坐标映射到原图。普通和大图片不追加图像重试。
- `tests/Snip.Core.Tests/OcrLanguageSelectionTests.cs`：中英候选、手动选择、缺少英语、其他语言及有界候选回归。
- `tests/Snip.Windows.Checks/TextWindowChecks.cs`：真实结果窗口中的中文空结果→英语成功→显示并翻译，及手动语言不被静默切换。
- `tests/Snip.Windows.Checks/NativeOcrCheck.cs`：原生英语 OCR 的 10/12/24 像素字号、贴近边缘的 ChatGPT 小截图语义与原图坐标检查。样例为公开合成内容，不是用户截图。
- `Directory.Build.props`、`docs/使用说明.md`：版本及 OCR/翻译模型区别说明。
