# 2.0.13 自定义截图快捷键

用户已确认长截图是误运行旧版导致，2.0.12 在笔记本屏幕正常。本轮不改长截图算法，也不自动替换离线翻译模型。

## 功能与修改文件

- `src/Snip.Core/HotkeyGesture.cs`、`Services.cs`：可配置组合、默认 Ctrl+Alt+A、按键合法性与服务契约；避免普通无修饰输入和系统保留 F12。
- `src/Snip.Infrastructure/HotkeyService.cs`：先注册新组合，再释放旧组合；冲突保持原快捷键，旧组合排队消息不触发新配置。
- `src/Snip.Infrastructure/HotkeySettingsStore.cs`：当前用户本地 JSON 原子保存，重启恢复，损坏配置报告后启动采用默认组合。
- `src/Snip.App/ViewModels/HotkeySettingsViewModel.cs`、`Views/HotkeySettingsWindow.xaml`、`.xaml.cs`：按键录入、保存、默认值草稿、冲突提示、保存失败恢复原注册，Esc 关闭。
- `src/Snip.App/ViewModels/MainViewModel.cs`、`Views/MainWindow.xaml`、`App.xaml.cs`：主窗口“修改”入口、动态快捷键、启动加载；设置窗口激活时抑制截图热键，避免录入当前组合触发截图。重复启动明确提示已有实例及新文件版本，提醒退出旧实例再运行更新版；主窗口标题显示运行版本。
- `src/Snip.Infrastructure/TrayService.cs`、`src/Snip.App/Services/FeatureHub.cs`：托盘菜单、提示随配置更新，编辑窗口引导不再固定写 Ctrl+Alt+A。
- `tests/Snip.Core.Tests/HotkeyGestureTests.cs`：危险/保留组合回归。
- `tests/Snip.Windows.Checks/HotkeyChecks.cs`、`Program.cs`、`UiGalleryCheck.cs`：真实 RegisterHotKey 冲突、实际键盘触发、新旧注册替换、配置重读、写入失败回滚、真实设置窗口录入和 Esc；增加设置窗口预览。
- `packaging/Validate.ps1`、`Directory.Build.props`、`docs/使用说明.md`：必跑热键检查、版本与使用步骤。

## 验证

本地完整 Release 构建无错误、无警告；75 项 Core 与 14 项在线协议检查通过。Windows 原生输入、窗口和浏览器验证完成后补充结果与下载链接。

## 离线翻译

按用户选择的下载约 1 GB、运行内存约 2 GB 预算，另行记录候选模型、公开评测出处和量化/推理兼容性。研究结论不等于本轮已经接入替换。截图中的 Snip.App 被 OCR 识别为 Snip，属于翻译前丢失信息；翻译模型不能恢复原图漏识别的后缀。
