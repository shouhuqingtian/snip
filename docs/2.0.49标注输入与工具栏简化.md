# 2.0.49 标注输入与工具栏简化

本版合并悬停智能选区、直接取消截图，以及以下三项调整：

- 去掉马赛克数字下拉，马赛克继续使用原有默认块大小。
- 新截图和独立编辑器默认线宽改为 6，仍可选其他线宽。
- 文字输入框按实际字形尺寸、字号和行数测量，空框也预留完整字形高度；输入文字和换行会重新测量，长内容到达图片边界后允许滚动，不影响最终原图尺寸。

## 修改文件

| 文件 | 修改 |
| --- | --- |
| `src/Snip.App/ViewModels/EditorViewModel.cs` | 默认线宽 6，移除无界面使用的马赛克大小选项列表；保留标注数据中的块大小。 |
| `src/Snip.App/Views/EditorToolbar.cs` | 移除马赛克数字下拉；屏幕选区和独立编辑器共用。 |
| `src/Snip.App/Views/EditorCanvas.cs` | 依据实际字形与行高测量输入区域，输入/换行时更新，显式顶部对齐与滚动；绘制笔迹时仍跳过文本布局。 |
| `tests/Snip.Windows.Checks/InlineTextChecks.cs`、`Program.cs` | 真实 64 号中英文字、逐字符可见区域和实际红色字形像素、多行增长、50%/100% 缩放、Ctrl+Enter、撤销重做、原图导出尺寸，默认线宽与下拉数量；接入默认桌面组，增加第 41 张界面预览。 |
| `.github/workflows/windows-targeted.yml` | 增加 inline-text 专项，支持与编辑交互/性能组合检查。 |
| `Directory.Build.props`、`docs/使用说明.md` | 2.0.49 版本和操作说明。 |

智能选区与取消确认的完整文件清单和专项证据见 [悬停智能选区](2.0.48悬停智能选区.md)。2.0.48 的 core/windows 验证通过后收到本次新增需求，主动取消其 deliver 阶段，不改写已有版本标签；统一以 2.0.49 提供安装包。
