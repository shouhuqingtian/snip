# 2.0.49 标注输入与工具栏简化

本版合并悬停智能选区、直接取消截图，以及以下三项调整：

- 去掉马赛克数字下拉，马赛克继续使用原有默认块大小。
- 新截图和独立编辑器默认线宽改为 6，仍可选其他线宽。
- 文字输入框按实际字形尺寸、字号和行数测量，空框也预留完整字形高度；输入文字和换行会重新测量，长内容到达图片边界后允许滚动，不影响最终原图尺寸。

| 文件 | 修改 |

| `tests/Snip.Windows.Checks/InlineTextChecks.cs`、`Program.cs` | 真实 64 号中英文字、逐字符可见区域和实际红色字形像素、多行增长、50%/100% 缩放、Ctrl+Enter、撤销重做、原图导出尺寸，默认线宽与下拉数量；接入默认桌面组，增加第 41 张界面预览。 |

[大字号 Windows 专项 39384816443](https://github.com/shouhuqingtian/snip/actions/runs/39384816443) 通过，[日志复核 39385000713](https://github.com/shouhuqingtian/snip/actions/runs/39385000713) 显示 50%/100% 两档均有 9412 个红色字形像素，逐字符区域、多行增长、Ctrl+Enter、撤销/重做及原图尺寸检查通过，默认线宽为 6，工具栏仅剩线宽/字号两个下拉。

首次组合检查 39384960315 的 25 项基础用例全部通过，性能比较发现历史 4 像素笔迹和新默认 6 像素笔迹输入不同，导致导出哈希不同。基准改为两边显式使用同一 4 像素历史样例；不修改默认 6，不删除像素哈希比较和性能门槛。修正后的组合验证、完整回归及安装包记录在完成后补充。
