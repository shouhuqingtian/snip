# 2.0.81 自由快捷键设置

## 问题与修改

2.0.80 的共享 HotkeyGesture.Validate 明确拒绝仅 Shift 加字母/数字，以及没有修饰键的普通按键，因此用户在截图设置页按 Shift+Q 仍保留原草稿。该拒绝发生在 RegisterHotKey 之前，属于程序校验限制，不能解释为 Windows 不支持。

删除以上两类限制，支持普通单键及 Shift/Ctrl/Alt/Win 组合，并补充小键盘、OEM 标点、常用编辑/锁定和媒体键的虚拟键校验及显示名称。截图、贴图和语音沿用共享校验。纯修饰键不作为主键；F12 保留明确的 Windows 保留键错误，实际系统占用/保留组合仍由 Windows 注册结果决定，失败保留原工作快捷键。Esc 在录入页面用于取消/关闭，贴图页面的空白 Delete/Backspace 仍用于清除绑定；不宣称能够覆盖 Windows 安全按键或所有硬件 Fn 键。

截图设置页在选择单键/Shift 组合时提示可能影响普通输入，不自动应用草稿或弹出额外确认；适当增加窗口高度以显示完整提示。三类录入页解析输入法/死键事件提供的真实按键，不将 IME 处理占位键当作快捷键。没有安装新的全局键盘钩子或更换注册后端。

## 文件与验证

- HotkeyGesture.cs：校验及键名；HotkeyGestureTests / PinHotkeySettingsTests：配置往返、Shift/单键、小键盘/OEM、非法修饰标志、保留键。
- HotkeySettingsViewModel、HotkeySettingsWindow：保存前影响提示、录入事件和窗口布局；贴图/语音录入页使用同样的实际按键解析。
- HotkeyChecks：在真实设置页录入并保存 Shift+Q，确认草稿不提前应用、持久化、真实按键全局触发和占用冲突；同样验证普通单键 Q / Space、小键盘 Num1 和 OEM 分号。保留全部截图/逐像素回归。

本地构建与 Core / 协议检查已通过；Windows 录入/注册/截图回归及正式安装验证待完成。Windows runner 使用公开样例和默认键盘布局；不把输入法事件解析分支当作真实中文 IME 或每一种键盘布局均已验收。
