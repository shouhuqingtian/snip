# 2.0.21 开机自启、默认翻译与基础词典

## 行为

- 主窗口新增“通用设置”，可开关当前用户的开机自启，默认关闭；开启后登录 Windows 常驻托盘，不重复弹窗。关闭只删除本软件启动项。便携版需固定路径；Windows 系统禁用启动项时需在系统中启用。
- 文字工作台可选在线大模型、离线模型、基础词典，点“保存为默认”保存方式和方向。新截图及软件重启沿用。通用设置也能保存。保存不执行翻译；失败不自动切换到另一服务器；配置在线密钥不改变保存的方式。
- 基础词典采用随软件内置的 12151 词条（835467 字节），支持英中查词、常见短语和中文反向查词。无需下载，不联网、不启动本地模型；不是整句翻译。显示未收录词，限制输入和输出条目，支持取消。索引只在首次查词时创建，其他模式不加载。
- 原有在线密钥与模型保留；没有新版默认设置时兼容旧在线默认值，明确保存新方式后以新方式为准。损坏的新版设置不会静默重新启用在线服务。
