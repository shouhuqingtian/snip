# 2.0.42 手动长截图与界面调整

合并本轮三项反馈：

- 手动长截图：按住左键向下拖过网页可见正文约 60% 高度即滚动；上移至约 55% 以上暂停，回到下方继续，松开完成。保留首次下拖门槛和缓冲带，避免只按住或轻微抖动就滚页。
- 工具栏：移除 `#FF3B30` 一类颜色代码输入框，屏幕选区与独立编辑窗口保留色块选色、线宽、字号、马赛克及填充。
- 文字工作台：“移回当前屏幕”移到底部关闭按钮旁，共用轻量、低对比样式；悬停显示用途说明，关闭保留独立 Esc 键帽。

## 发布检查补充

2.0.40 的原生中下部滚动/暂停/继续检查通过。加入两项界面调整后的 2.0.41 正式检查中，公开选中文字网页在暂停后的下一轮拼接失败，模态错误提示又阻塞了测试退出，最终超时；2.0.41 未发布。

本次为原生测试提供可注入的失败报告：生产默认仍显示错误提示，测试直接抛出原始错误，避免等到整个任务超时才发现具体失败。公开测试页通过标题暴露自身 `scrollY`，在暂停稳定后核对累计拼接位移，不把拼接高度本身当作真实滚动的证明。该元数据仅属于版本控制的公开 fixture，不读取或记录用户网页标题、文字或 URL。

同时收紧帧稳定判断：旧的稀疏全图均值可能忽略大面积白底上的小范围文字运动，新增回归图可以复现这种误判；现在要求局部显著内容也停止变化，并仍需连续两次稳定采样。保留有界等待、取消和严格重叠匹配的误差/歧义阈值。手动滚动的目标步长改为有效视口的 30%，为浏览器/Windows 对滚轮突发的加速保留更大的重叠余量；仍根据已确认位移调整步长。相比半视口目标，主动减少每轮前进距离，优先保证重复段落场景的可靠拼接，速度数据重新实测，不沿用旧版 2.7 倍结论。
