## 3. 必须明确的交互

### 3.1 主截图流程

已确认：选区形成后显示浮动工具栏，直接在选区里标注；独立编辑窗口保留为可选入口。

工具栏需适应显示器边缘、负坐标和混合 DPI，并避免挡住用户正在绘制的区域；导出图片不含工具栏及遮罩。

绿色对勾已确认定义为“合成截图、复制到剪贴板、关闭截图遮罩并返回原应用”。保存按钮只负责另存为并保留编辑；复制失败时保留截图及标注，不静默关闭。

文字在图像位置直接输入和修改；颜色、线宽、字号采用对应工具的浮动属性面板，纳入本方案最终确认。取消当前未提交笔画与取消整个截图会话分开处理，避免 Esc 一次直接丢失已提交标注。

### 3.2 OCR 与翻译

- 最新选择覆盖此前在线方案：用户要求先做离线，在线服务后续补充。
- 离线 OCR 优先评估 Windows 自带文字识别组件，目标为中英文；检查语言组件可用性，缺失时明确提示所需安装步骤，不要求用户填写在线密钥。
- 已确认本轮同时实现离线 OCR 和中英互译，用户接受额外模型下载。
- 翻译默认采用本地 CPU 推理方案，模型/分词器分为中文到英文、英文到中文两个方向。评估 ONNX Runtime 与公开可分发模型，实际选型需确认模型许可证、文件版本、校验及分词器兼容性，不把未验证的模型写成已完成。
- 模型包与安装程序分离。首次使用前提供模型安装状态、体积、下载进度、失败重试和取消；模型齐备后断网仍可翻译。模型缺失时明确提示，不能返回空结果充当成功。
- 默认 OCR 结果窗口保留原文并提供中译英/英译中选择与翻译结果复制；独立编辑窗口支持同样流程。长图识别需按引擎尺寸限制分块，不隐式缩小导致文字不可读。
- 离线推理不上传截图或识别文字；模型/语言组件的安装与本地推理分别说明，不能把在线翻译缓存称为离线翻译。
- 结果窗口提供复制、失败提示和取消；未实现的功能不显示为可用。
- 保留在线服务扩展契约，实际供应商及凭据配置在后续阶段确认。

### 3.3 长截图

已确认采用自动滚动，优先支持 Chrome/Edge 普通网页；其他应用不支持时明确提示。本轮不以手动滚动替代自动滚动功能。

拟定验收范围：

- 选取浏览器网页内容区域，激活对应浏览器窗口，自动向下滚动采集。
- 根据重叠内容去重并拼接，提供进度、预览、完成及 Esc 取消。
- 检测到底、窗口变化、页面不滚动和拼接置信度不足，避免生成静默重复或错误拼接的图片。
- 保留原网页可见内容，不把遮罩、工具栏或浏览器地址栏拼入长图。
- 设置采集时间、帧数和最终图像大小上限，避免无限加载页面持续占用资源。
- 嵌套滚动容器、虚拟列表、动态视频和复杂固定元素不默认视为已支持；无法可靠采集时明确说明原因。

不得将普通多张图片纵向堆叠称为已实现可靠滚动拼接。

### 3.4 贴图、表情和分享

- 贴图范围已确认：桌面置顶显示、拖动位置、滚轮缩放、透明度、鼠标穿透、Esc/右键菜单关闭。鼠标穿透开启后，通过托盘“贴图管理”恢复交互或关闭，避免无法操作。
- 表情范围已确认：内置通用表情与用户导入图片贴纸，不复制微信专有素材。贴纸进入共享标注文档，可选择、移动、缩放、删除及撤销/重做。
- 分享已要求直接选择微信联系人并发送，不能以复制图片或系统分享面板作为此功能完成。
- 用户已提供 Windows 微信版本 4.1.15.12。当前项目没有已验证的联系人/发送接入，仍需确认是否接受通过微信窗口自动操作实现；该方案要求微信已登录、针对该版本适配及 Windows 实机验证。
- 此次云环境无法访问微信官方开发文档，尚不能确认可用于本需求的官方接口。不能将未核实的接入能力写成已可实现或已验证。
- 若采用界面自动化，需选择明确的收件目标并预览图片，用户点击发送后才执行；目标无法核实时停止并显示原因。开发测试使用模拟适配器及受控测试场景，不擅自给真实联系人发送图片。

## 5. 确认后的实现原则

- 延续 C#、WPF、.NET 8、MVVM 和现有 Core / Infrastructure / App 分层。
- 复用已有标注模型、渲染和撤销历史；选区编辑与独立编辑共享同一文档，不维护两套结果不一致的实现。
- 新增 OCR、翻译、长截图、贴图和分享服务，按确认方案注入；不添加虚假的可用入口。
- 每完成一个功能记录修改文件、验证结果及限制。
- 完成后生成新版源码、便携包和安装包，通过现有 GitHub 仓库下载目录交付；版本号随实际新增范围更新。
- Linux 继续执行构建和核心测试；Windows 相关检查及用户实机反馈分别记录，不将编译通过视为桌面交互验收通过。

## 7. 验收标准与实施顺序

1. **选区直接编辑**：选区出现参考图结构的浮动工具栏；工具栏在屏幕边缘仍可操作，多屏/DPI 下标注与输出对齐；原有绘图、撤销/重做、PNG 保存均可使用。对勾复制后退出，独立编辑入口保留。
2. **标注和选区增强**：表情及 PNG/JPEG 图片贴纸可移动/缩放/删除/撤销；其他标注可缩放，矩形可填充；窗口自动选取、放大镜及方向键单像素微调可用，取消行为不误丢已提交编辑。
3. **贴图**：合成结果置顶显示；可移动、滚轮缩放、调透明度及鼠标穿透；可从托盘恢复或关闭；贴图再次复制/保存与显示一致。
4. **离线 OCR**：语言组件齐备时断网识别中英文，返回可复制文字；组件缺失及超大图都有明确处理，不依赖在线密钥。
5. **离线翻译**：两个方向模型完成下载及校验后，断网完成中英互译；下载失败可重试，取消和长文本处理可用，原文与译文均保留。
6. **浏览器自动长截图**：Chrome/Edge 普通可滚动网页可自动采集、重叠去重及拼接；可取消、预览并编辑/导出；其他应用、无滚动区域、动态内容或低置信度拼接明确提示，不能输出错误长图后仍报告成功。
7. **微信发送（接入方式确认后）**：针对 4.1.15.12，用户能选择明确联系人、查看目标和截图、点击发送；未登录、窗口/版本不匹配或目标无法核实时明确失败，不自动退化为“已复制”等同“已发送”。实际发送需在用户 Windows 环境验收，未验收不得标记完成。

以上按顺序实现与验证，每项完成说明修改文件。Linux 可验证的构建/核心测试与 Windows 实机检查分别记录；遇到某项外部阻碍继续其他独立功能，保留未完成项，不静默缩减范围。
