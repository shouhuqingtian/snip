# 2.0.15 默认 OCR 与翻译可用性

## 行为

截图文字识别使用 Windows 本地 OCR，与在线密钥、Hy-MT2 翻译权重独立。无需配置任何翻译资源即可查看截图、修改识别文字和复制。

从截图工具栏点击“文字识别 / 中英翻译”，仍然先执行 OCR；所选翻译方式没有可用资源时，保留 OCR 结果并隐藏尚无结果的翻译面板，以文字提示下载或配置入口。不报缺少翻译模型错误，不自动下载，不自动联网，不偷偷切换到其他翻译方式。手动点击翻译遵循相同规则；已有译文不会因资源缺失被清除。

资源检查只读取文件存在性/大小或在线配置，不读取整个 951 MB 模型、不加载推理进程、不请求在线服务。实际离线翻译仍执行完整 SHA256 校验，实际在线请求仍执行认证与超时处理。模型安装完整但缺微软运行库、文件同尺寸损坏或推理失败，继续显示具体错误并保留 OCR。

Windows 仍需安装截图文字对应的 OCR 语言组件。缺少时保留截图，提示在 Windows 设置→语言和区域中添加中文/英语及文字识别组件。软件未内置另一套独立 OCR 引擎，也不把翻译模型当作 OCR。

## 修改文件

- `src/Snip.Core/Services.cs`：翻译服务增加不加载模型、不联网的可用性查询。
- `src/Snip.Translation/ModelStore.cs`、`OfflineTranslator.cs`：快速检查权重和必需推理文件的存在性/大小，实际推理继续完整校验。
- `src/Snip.Translation/OnlineTranslator.cs`：读取在线配置判断可用性，缺密钥、地址/模型无效、无法读取配置或解密时返回不可用；保留取消。
- `src/Snip.App/ViewModels/TextResultViewModel.cs`：默认回退到可编辑、可复制 OCR，隐藏空翻译面板，记录不包含原文的技术阶段。
- `src/Snip.App/Services/FeatureHub.cs`：初始在线选择和设置保存后的选择需要已保存密钥。
- `tests/Snip.Translation.Checks/OnlineTranslationChecks.cs`：无联网可用性、取消、未安装模型不产生文件的回归。
- `tests/Snip.Windows.Checks/TextWindowChecks.cs`：真实 FeatureHub 和 WPF 无模型/无密钥默认流程、手动重试、缺 Windows 语言组件保留窗口。
- `tests/Snip.Windows.Checks/NativeOcrCheck.cs`：原生 Windows OCR 在全新无模型/无在线配置目录执行，确认实际结果可见、可修改、可复制到系统剪贴板且不产生翻译文件。
- `Directory.Build.props`、`docs/使用说明.md`、`README.md`：版本、默认 OCR 使用说明及当前下载入口。
