# 2.0.54 桌面长截图冻结表头修复

用户反馈桌面手动长截图在表格窗口频繁显示“对齐暂停”。检查发现两项明确缺陷：桌面复用了网页匹配的 20% 固定首尾区域限制；同时按整个选区高度的 1/4 累计滚动距离，大块工具栏/冻结表头会把真正滚动的正文挤得很小，正文已经失去重叠时仍未加入下一帧。

新增公开的 600 像素高画面回归：400 像素固定表头、40 像素固定底栏，正文只有 160 像素。每次滚动 32 像素，2.0.53 路径在测试中复现暂停；修复后要求逐像素匹配完整长图，固定区域只出现一次。用户截图和业务内容不进入代码或 CI。

## 修改文件

| 文件 | 修改 |
| --- | --- |
| `src/Snip.Core/DesktopScrollMatching.cs` | 新增桌面专用运动匹配：同时排除源点与目标点上的静止区域，正反方向联合判断，固定首尾区域不受 20% 限制。最多 512 个分布式锚点限制计算量，支持取消；保持原有误差/唯一性门槛，重复内容不猜测。增加锚点数、候选数、误差、唯一性差距、首尾范围与拒绝原因等技术诊断。 |
| `src/Snip.Core/ManualScrollCaptureSession.cs` | 桌面按有效运动区域及时接收小步滚动，不再等待整个窗口的 1/4；采用联合方向判断，避免先反向检测误判。保留稳定帧、显式完成、暂停保留与取消保护。原浏览器匹配路径不变。 |
| `tests/Snip.Core.Tests/DesktopScrollMatchingTests.cs` | 复现旧算法无法描述大冻结表头；校验小步连续滚动、首尾只保留一次及完整像素、正反方向、无关画面和重复行的保守拒绝。 |
| `tests/Snip.Windows.Checks/DesktopScrollChecks.cs` | 在原表格/聊天真实外进程样例之外，增加半屏以上冻结表头、固定状态栏和原生单格滚轮样例；选区包含固定 UI，整张结果逐像素验证。 |
| `Directory.Build.props`、`docs/使用说明.md` | 版本与说明更新。 |

## 验证

正在进行本地和真实 Windows 验证；完成后补充正式构建、安装和下载校验结果。

## 边界

本次修复针对固定区域占比较大的桌面选区，不能从完全相同的空白/重复内容中推断唯一滚动距离。一次滚动跨过全部重叠、动态重排或多个独立滚动区仍可能暂停；保留已采集部分而不强行拼接。具体 Excel、WPS、ChatGPT 桌面版本和用户的混合 DPI 屏幕仍需实机验证。
