# 2.0.54 桌面长截图冻结表头修复

用户反馈整个窗口和仅选正文都会频繁显示“对齐暂停”，稍快滚动也容易触发。检查复现三项缺陷：桌面复用了网页匹配的 20% 固定首尾区域限制；按整个选区高度的 1/4 累计滚动距离，大块工具栏/冻结表头会把正文挤得很小；仅等画面连续停稳才加入中间帧，连续滚动即使每对相邻画面可以可靠匹配，也会等到失去重叠才尝试拼接。

新增公开的 600 像素高画面回归：400 像素固定表头、40 像素固定底栏，正文只有 160 像素。每次滚动 32 像素，2.0.53 路径在测试中复现暂停；修复后要求逐像素匹配完整长图，固定区域只出现一次。用户截图和业务内容不进入代码或 CI。

另增加仅选正文的连续滚动回归：200 像素高选区以 32 像素连续移动，累计 192 像素，中间没有静止画面。停稳后才拼接的路径复现丢失内容；新路径必须完整生成 392 像素高长图，并拒绝混入无法匹配的动画噪声。

## 边界

本次修复针对固定区域占比较大的桌面选区，不能从完全相同的空白/重复内容中推断唯一滚动距离。一次滚动跨过全部重叠、动态重排或多个独立滚动区仍可能暂停；保留已采集部分而不强行拼接。具体 Excel、WPS、ChatGPT 桌面版本和用户的混合 DPI 屏幕仍需实机验证。
