# 2.0.68 按住快捷键语音输入

程序在托盘运行时，将光标放在普通文字输入框，按住可自定义的全局快捷键录音，松开后调用在线 ASR 识别并在原输入位置写入文字。默认语音组合为 Ctrl+Alt+Space，与截图快捷键分开；需要先打开“语音输入”填写服务并保存启用。主窗口与托盘均有设置入口，托盘可查看上次识别结果。

首版提供硅基流动 SenseVoiceSmall、OpenAI transcribe/whisper 与自定义 OpenAI audio/transcriptions 兼容接口。模型与完整接口地址可修改，使用独立密钥，或显式复用同服务域名/地域的翻译密钥。DeepSeek 等普通聊天接口、AI 发音 TTS 接口不能代替 ASR；实际模型可用性和费用以服务商为准。

## 录音与写入

只有主动按住快捷键后录音，使用 Windows 默认麦克风，16 kHz 单声道 PCM，最长 120 秒。录音为内存与匿名管道传输，不写录音文件；结束、取消或退出时关闭辅助进程释放麦克风，WAV/PCM 缓冲清零。录音与有时会阻塞的辅助功能查询放在有期限的进程中，并使用 Windows job 在父进程退出时回收。输入保护钩子运行在独立消息线程，只保存位置身份和是否变化，不保存按键内容；松键另有短间隔后台检查，避免主界面繁忙时持续录音。

录音状态窗不激活目标窗口。识别完成后比较原窗口、原生焦点与 UI Automation 输入元素身份；移动输入位置或无法确认可编辑时保留结果，不自动写到其他窗口。已识别到的密码框不上传语音，不写入；只读/未知控件不自动写入。写入使用带标记的 Unicode 输入，保留中英与表情，不动剪贴板，不自动按回车发送；识别中的换行/制表符变为空格，控制字符不输入。特殊应用、管理员窗口和不接受此输入方式的控件可能需要手动复制结果。

Esc 或状态窗关闭按钮取消本次录音/识别。快捷键仍按住、正在识别或输入时不叠加第二段录音。只保存本次运行的上次识别文字，退出清空；状态提示和诊断不显示/记录语音、识别文本、服务地址或密钥。诊断只记录阶段、字符数、写入数和受控技术错误类型/码。

## 设置范围

语音输入设置独立保存在本机 `voice-input.json`，密钥使用当前 Windows 用户 DPAPI 加密；快捷键和服务配置一次原子保存。冲突/保存失败保留旧快捷键和设置。切换服务会清除未保存的密钥输入；更换接口地址不会自动沿用旧独立密钥；复用翻译密钥需显式选择并校验同域名/地域。

这组新增设置目前不进入已有账号同步或加密文件迁移；已有翻译/发音等配置的同步和迁移范围不变，语音输入可复用已同步的翻译密钥。没有修改服务端或旧版账号协议。

## 修改文件

- Core `VoiceInput.cs`：设置/凭据契约、录音上限、PCM/WAV、输入文字净化。
- Translation `OnlineTranscriptionService.cs`：multipart 语音转文字、有限超时、取消、返回上限和受控错误。
- Infrastructure `TranscriptionSettingsStore.cs`、`WindowsMicrophoneRecorder.cs`、`VoiceWorkers.cs`、`VoiceWorkerJob.cs`、`VoiceInputTarget.cs`：DPAPI、默认麦克风、管道/job 进程生命周期、输入身份查询和 Unicode 写入。
- App `VoiceInputController.cs`、设置 ViewModel/窗口、状态窗/结果窗、主窗口/托盘/组合根：按住/松开流程和用户配置入口。
- Core/协议/Windows 原生检查：合成 WAV、真实热键和焦点输入、凭据、取消及辅助进程回收；不使用用户密钥或付费模型请求。
