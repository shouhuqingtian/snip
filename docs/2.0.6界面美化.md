# 2.0.6 全界面美化

统一采用中文浅色界面：柔和灰白背景、绿色主操作、圆角白色卡片和清晰的文字层级。截图工具栏使用同尺寸矢量图标，配色可直接点击色点；悬停、按下、选中、键盘焦点、禁用状态保持一致。

## 验证与范围

本地构建和 Core 测试验证代码；Windows CI 运行实际主题、窗口渲染、文字识别/翻译、复制、编辑、Chrome 既有回归。实际结果在便携包的 `validation/validation-desktop.json` 中，真实窗口预览在 `validation/ui-previews/`。合成图片、识别与译文仅用于界面预览，不代替原生 OCR 和真实模型检查。

此次调整应用自有窗口与控件。Windows 文件选择、系统消息框和托盘菜单沿用系统外观；窗口移动、系统标题栏、最大化和关闭操作保持 Windows 的交互习惯。多显示器混合 DPI 仍需用户实机验收。
