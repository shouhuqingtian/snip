# 2.0.46 直接操作标注，移除选择按钮

## 操作

屏幕选区与独立编辑窗口共用工具栏，移除原“鼠标／选择”按钮，矩形成为第一个工具。当前绘图工具为矩形、椭圆、箭头或文字时：

- 点击已有标注选中，按住框线或标注内容拖动即可移动；悬停显示移动光标。
- 选中后显示八个控制点，拖控制点缩放，其余框线仍用于移动，不再把整条边都当成缩放区域。
- 空心矩形/椭圆内部可继续画新标注；填充形状、文字、贴纸按可见区域选取，重叠对象优先选择最上层。填充椭圆包围盒中没有实际图形的角落不会抢占绘图。
- 移动后继续保留当前绘图工具，点击空白处可接着画；导入贴纸也不会进入已无按钮的隐藏选择模式。
- 双击文字直接编辑，Delete 删除，Ctrl+Z / Ctrl+Y 撤销与重做。点击及不足约 3 DIP 的抖动不创建移动/缩放历史。

画笔和马赛克优先绘制，以便连续描画、覆盖已有文字或标注；需要移动这些标注时，切换矩形等常用绘图工具后直接点选即可。控制点和命中容差随实际画布缩放保持可用，覆盖独立编辑器及屏幕选区的不同 LayoutTransform。
