# 2.0.47 全屏选区提示与工具栏避让

## 修复

全屏或贴近屏幕上边缘的选区，工具栏可能回退到左上角，与原来固定在 `(16,16)` 的尺寸/操作提示重叠。现在按工具栏和提示的实际测量尺寸，在同一窗口 DIP 坐标内安排位置：发生冲突时，提示优先放在工具栏下方；下方没有空间时改放上方，必要时预留顶部提示行。

提示保持可见且不拦截鼠标，小屏或高缩放下按可用宽度换行。工具栏换行、窗口尺寸变化、重新选择区域后重新安排。修改只影响截图辅助界面，不更改选区、原图像素、标注或导出尺寸。
