# 2.0.28：三种 OCR、共用在线配置与默认设置

文字工作台支持系统识别、增强离线识别、在线视觉识别。选择后点击“重新识别”；点“保存识别默认”后，新截图和软件重启继续采用该方式。每个已经打开的工作台保留自己的选择，切换不会直接发出请求，也不改变翻译方式。

## 使用

1. 截图 → 识别文字，在上方“文字识别”下拉选择方式。
2. **系统识别（免下载）**：使用 Windows OCR 语言组件，不上传截图、不加载增强模型。
3. **增强离线识别**：使用现有 PP-OCRv6 small 中英混合引擎。未安装时，从更多设置下载 / 修复约 31 MB 模型；下载后重新识别当前截图。识别结束释放模型，已有故障回退系统 OCR 的能力保留。
4. **在线视觉识别**：在线设置共用翻译的当前服务、API 地址和加密密钥。可以单独填写“OCR 视觉模型”；留空时采用翻译模型，但该模型必须支持图片输入。通义千问可填 `qwen-vl-plus` 或 `qwen-vl-max`；候选以账户、地域和服务商实际支持为准。
5. 点“保存识别默认”保存 OCR 方式；翻译方向和方式仍通过“保存翻译默认”独立保存。

DeepSeek 的 `deepseek-chat`、`deepseek-reasoner` 为文本模型，不能直接识图；遇到这两个名称会在上传前提示更换视觉模型。不会把通义千问模型发往另一个服务地址来尝试适配。在线 OCR 和翻译共用当前选中的服务配置，因此需要同时可用的服务及各自模型。

## 请求、失败与隐私

- 在线 OCR 会发送当前截图；在线翻译继续只发送识别后的文字。选择默认在线意味着以后打开识别窗口时也使用在线 OCR。系统和增强离线模式不读取在线密钥、不发送截图。
- 兼容 OpenAI Chat Completions 的 `image_url` PNG 输入，一次请求，不自动重试、换服务或联网回退。服务是否支持具体模型需在用户账号上验证。
- 每张在线截图最多 1600 万像素、8 MiB PNG，响应最多 1 MiB、识别文字最多 10 万字符；60 秒超时，可取消或关闭窗口。超限可缩小选区或使用增强离线模式。
- 在线结果用于提取文字，不翻译、不自动纠错；不伪造逐字坐标或置信度。模型仍可能漏字或输出错误，涉及编号、金额等需核对原图。
- 失败、截断、限流、认证错误时保留窗口和已有文字，提示切换方式；服务返回的错误正文不展示、不记日志。取消或关闭不会启动另一个引擎。
- 默认方式仅保存枚举，不保存图片或识别文字；密钥仍使用 Windows 当前用户 DPAPI 加密。旧版没有独立 OCR 默认值时，沿用增强已安装且启用的状态；否则使用系统识别。损坏的默认文件回到系统模式，避免意外上传。
