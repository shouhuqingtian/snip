# 2.0.51 网页大选区、坐标取色与复制反馈

本版处理三项反馈：成功复制截图后显示短暂提示；刚进入截图、鼠标不动时保持初始选框；增加按下鼠标滚轮（中键）复制，滚动滚轮仍不会复制。

根据后续确认追加：普通网页直接选择整个可见正文（包括侧栏，排除标签栏/地址栏），不再细分普通面板；网页弹窗及弹窗内嵌页仍优先当前弹窗。放大镜下方显示全桌面物理像素坐标、`#RRGGBB` 色值；Ctrl+C 只复制色值并保留截图，Enter/中键仍复制图片。坐标保留副屏负坐标，取色读取冻结原图，避开遮罩、提示与后续页面变化。
