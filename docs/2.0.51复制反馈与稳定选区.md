# 2.0.51 复制反馈与稳定选区

本版处理三项反馈：成功复制截图后显示短暂提示；刚进入截图、鼠标不动时保持初始选框；增加按下鼠标滚轮（中键）复制，滚动滚轮仍不会复制。

## 修改文件

| 文件 | 修改 |
| --- | --- |
| `src/Snip.App/Services/SelectionSession.cs` | 初始不启动内部区域识别，真实移动超过 3 DIP 后才启用；只应用当前鼠标请求的结果，左键开始选区即锁定并释放检测；忽略未完成拖选/绘制中的确认。 |
| `src/Snip.App/Views/SelectionWindow.cs` | 中键复用 Enter 的确认流程并拦截事件；左键开始时锁定；提示文字加入中键。 |
| `src/Snip.App/Views/EditorToolbar.cs`、`EditorWindow.xaml.cs` | 独立编辑器中键复用工具栏完成动作，导出/绘制时不重复执行。 |
| `src/Snip.App/Services/CopyFeedbackExport.cs` | 仅图片剪贴板写入成功后请求提示，失败和 PNG 保存不显示复制成功。 |
| `src/Snip.App/Services/CopyNotificationService.cs`、`Views/CopyNotificationWindow.cs` | 在截图窗口关闭后显示一张约 1.2 秒的深色勾选提示；不激活、不抢焦点、鼠标穿透；限制为一个窗口，支持取消排队提示和释放。 |
| `src/Snip.App/App.xaml.cs`、`Services/CaptureCoordinator.cs` | 所有图片复制入口共用反馈；再次截图前隐藏当前/排队提示，退出时释放。 |
| `tests/Snip.Windows.Checks/CaptureFeedbackChecks.cs`、`Program.cs` | 真实鼠标中键、滚轮/拖动/重复输入、剪贴板像素；过期且仍覆盖新位置的结果不能应用、手动点击锁定；成功/失败提示、焦点/穿透/自动关闭、下一次截图不含提示、独立编辑器及销毁；第 43 张预览。 |
| `tests/Snip.Windows.Checks/HoverRegionChecks.cs`、`SmartBrowserChecks.cs` | 初始静止不启动检测，移动后仍能识别大区域和网页弹窗；保留超时/取消/回收回归。 |
| `.github/workflows/windows-targeted.yml`、`Directory.Build.props`、`docs/使用说明.md` | 新专项入口、2.0.51 版本和使用说明。 |
