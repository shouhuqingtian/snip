# 2.0.58 私有账号与密钥同步

## 行为与使用

主窗口新增“账号与同步”。在自己的 Ubuntu 阿里云实例部署服务并接入现有 HTTPS 域名后，工作电脑注册一次自用截图账号，家里电脑输入同样的服务地址、账号和密码登录，即可读取加密的服务配置。它是自建账号，不使用阿里云账号密码。

同步翻译/在线 OCR/AI 语音的密钥、服务地址、文本/视觉/语音模型、音色、速度、当前服务与默认方式；截图、OCR 原文、译文、历史、贴图、快捷键和模型文件不上传。未登录不连同步服务器。登录且开启自动同步后约每 30 秒检查一次，无变化使用 304 响应，不重复传输配置或加载 AI 模型；网络失败退避至最多 5 分钟，手动同步仍可立即重试。

现有本机配置首次遇到不同云端配置，或两台电脑都修改后，会暂停并提示选择方向。导入前关闭在线/语音/通用设置窗口，避免覆盖未保存的编辑；临近应用时再次检查本机配置指纹。退出此设备保留模型密钥和本机服务配置，取消排队中的下载，其他设备仍可使用。

部署包的 [Ubuntu 操作说明](../packaging/account-sync/README.md) 与 Nginx 片段均为可审阅文件。脚本只创建当前部署目录、生成私有邀请码和启动本机端口容器，不自动修改现有站点、证书、SSH 或阿里云安全组。实际阿里云实例和域名尚未连接或部署，不能将本地/CI 验证写成用户服务器已上线。

## 数据保护与边界

- 客户端 PBKDF2-SHA256（600,000 次）生成主密钥，HMAC 不同用途标签分离认证凭据与配置加密凭据；原始密码不上传或保存。服务器用 ASP.NET Identity 再哈希认证凭据，不持有配置解密凭据。
- AES-256-GCM 配置包有随机盐、nonce 和认证标签；包内绑定云端版本，拒绝篡改、错误密码和不匹配版本。单包最多 512 KiB 明文。客户端收到后通过现有存储验证器验证并按当前 Windows 用户重新 DPAPI 加密。原有 DPAPI 配置文件不能直接跨机复制。
- 客户端令牌和解密凭据由 DPAPI 保护。服务器仅存令牌哈希，单设备令牌 30 天、每账号最多 8 个会话；邀请码受邀注册，单实例最多 100 个账号，登录失败锁定与请求限流。只允许 HTTPS 外网服务地址，本机测试可 HTTP；不跟随 HTTP 重定向、不自动切换第三方服务。
- 上传使用 If-Match 版本比较，服务器用原子文件替换拒绝并发旧版本；本机四文件导入有只含 DPAPI 密文的持久回滚记录，异常/崩溃后恢复，不写明文密钥临时文件。日志不包含账号、域名、密钥、密码、令牌或配置正文。
- 密码忘记后不能直接解密云端密钥；仍保留本机配置的设备可以新建账号重新上传。第一版不提供密码重置/修改、开放注册、浏览器管理、多副本数据库或同步模型文件。Ubuntu Docker 镜像拉取及既有 HTTPS 配置仍依赖用户服务器实际环境。
