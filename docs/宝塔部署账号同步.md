# 在宝塔部署自用截图账号同步

目标服务器：用户提供的 Ubuntu x64、2 核 2 GiB、已安装宝塔；域名 `bilibilil.online`。

2.0.65 客户端默认同步地址为：**`https://8.148.242.29/selfsnip/`**，也可手动填写 `https://bilibilil.online/selfsnip/`。使用 IP 地址时，站点须接受该 IP 的 HTTPS 请求，证书须受系统信任且包含该 IP；仅域名证书不适用。以下保留既有域名网站的部署步骤。这是自用截图自己的账号，不是阿里云或宝塔账号。既有网站首页可以保留。

## 1. 复用已有 HTTPS 网站

用户已确认宝塔中已有 `bilibilil.online` 网站并启用 HTTPS。直接使用该站点，保留原网站目录、证书、首页和其他应用；不需要为同步另建数据库。

本任务环境对该域名的公开网络访问受限，未能从这里独立验证解析或证书；这不是域名故障的证据。最终以步骤 3 的 HTTPS 健康接口结果为准。

## 2. 上传并安装同步服务

下载 [2.0.64 服务器部署包](https://github.com/shouhuqingtian/snip/releases/download/v2.0.64/self-snip-sync-server-2.0.64.zip)。在宝塔“文件”中上传并解压到独立目录，例如 `/opt/selfsnip-deploy/2.0.64/`。目录里应直接包含 `install-systemd.sh` 和 `linux-x64/`；如果解压多了一层文件夹，请进入实际目录。

宝塔终端执行：

```bash
cd /opt/selfsnip-deploy/2.0.64
sudo bash install-systemd.sh
curl -fsS http://127.0.0.1:5080/health
```

健康检查应返回 `{"status":"ok","version":1}`。这个方案无需先安装 Docker 或 .NET，不会下载翻译/OCR 模型。脚本只创建本应用的用户、服务、目录和服务配置，不更改现有网站、安全组及数据库。

服务只监听本机 5080，因此无需在阿里云安全组开放 5080，也不使用数据库端口。具体资源上限、数据位置、备份和回退见 [部署包说明](../packaging/account-sync/README.md)。如果 5080 已被占用，应先确认占用服务，不要结束其他应用。

## 3. 在该站点加入 Nginx 配置

以下仅适用于宝塔使用 **Nginx** 的网站。若面板使用 Apache/OpenLiteSpeed，不能直接粘贴 Nginx 语法，需要改用对应反代配置。

进入宝塔 → 网站 → `bilibilil.online` → 设置 → 配置文件，先备份原配置。在现有 `server { ... }` 内、与其他 `location` 同级加入下面一段。已有 `/selfsnip/` 时先核对归属，不重复添加。不要覆盖整个站点配置或改动面板的 SSL 证书段。

```nginx
location ^~ /selfsnip/ {
    # 宝塔可能在同一 server 中监听 80 与 443；同步接口仅允许 HTTPS。
    if ($scheme != "https") { return 403; }
    proxy_pass http://127.0.0.1:5080/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header Authorization $http_authorization;
    client_max_body_size 1m;
    proxy_connect_timeout 5s;
    proxy_send_timeout 30s;
    proxy_read_timeout 30s;
    proxy_no_cache 1;
}
```

使用宝塔检查 Nginx 配置并重载；终端也可先执行 `sudo nginx -t`，成功后通过面板重载。**宝塔安装的 Nginx 可能不在 PATH 中**，此时使用面板提供的检测/重载，不安装第二套 Nginx。

浏览器打开 **`https://bilibilil.online/selfsnip/health`**，应得到同样的健康 JSON。若为 404，检查 location 是否加入了正确域名；若为 502，先检查步骤 2 的本机健康接口及 `sudo systemctl status selfsnip-sync`；若是证书警告，先处理 SSL，不关闭客户端证书校验。

## 4. 两台 Windows 电脑登录

安装 [自用截图 2.0.65](https://github.com/shouhuqingtian/snip/releases/download/v2.0.65/SelfSnip-2.0.65-Setup-x64.exe)，先退出旧版托盘。

1. 工作电脑主窗口 → “账号与同步”，默认地址为 `https://8.148.242.29/selfsnip/`，确保宝塔站点及证书已支持 IP；也可手动填回已有有效证书的域名地址。
2. 第一次切换“注册新账号”，账号用 3–64 位英文、数字、点、下划线或短横线；密码至少 12 位，并确认密码。
3. 无需邀请码。注册前确认服务器已更新至 2.0.64；原 2.0.62 服务器仍要求邀请码，需要更新程序。旧账号及配置数据保留，不需要重新注册。
4. 点击“注册并登录”。顶部明确显示“注册成功，已自动登录”，下方另列配置同步结果；同步失败可重试，不需要重复注册。
5. 家里电脑填写同一个同步地址、账号和密码，切换“登录”并提交。不需要再次注册。
6. 自动同步改为约每 2 小时检查，登录、软件启动恢复会话和手动“立即同步”仍及时执行。
7. 两端都有配置时先选择保留云端或本机；可在替换前通过“配置迁移”导出加密备份。自动同步可关闭，退出账号保留本机配置。

账号密码还用于解密云端配置，首版没有找回或改密入口，请妥善保存。截图、识别原文、译文、本地模型及快捷键不上传。
