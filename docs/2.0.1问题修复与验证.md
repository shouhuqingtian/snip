## 使用及边界

先退出旧版托盘进程，再解压/安装 2.0.1。现有翻译模型无需重新下载。

在 Chrome/Edge 打开网页后，Ctrl+Alt+A 在正文内选择一个区域，点击 ↕ 网页截图按钮：

1. **捕捉整个网页**：自动识别当前浏览器正文视口，从顶部滚动到页尾，结果打开编辑窗口。输出当前浏览器视口宽度的整页长图，不含地址栏。
2. **捕捉可见网页**：只采集当前浏览器正文视口，不滚动。
3. **捕捉选定区域**：将已选择区域打开到独立编辑窗口，保留标注，不滚动。
4. **选定区域长截图**：保留选区宽度及高度，从当前位置向下自动滚动和拼接。

采集时不要切换窗口；Esc/取消可停止。普通网页为目标；嵌套列表、视频、动态布局、无限加载页面仍可能无法可靠拼接，软件会明确停止。90 秒、160 帧、24000 像素高度和 6000 万像素限制仍用于避免失控采集。

浏览器提供滚动位置接口时恢复原位置；没有接口时截图仍可进行，但网页留在采集结束位置。无法识别正文视口时会提示使用“选定区域长截图”，不会猜测地址栏高度。

OCR 仍需安装 Windows 的中文/英语文字识别语言组件。缺少组件、超时或模型未安装均会显示错误，窗口可操作；截图和识别原文不上传网络。

发行包的 ZIP 完整性、安装包内 EXE 与便携 EXE 一致、第三方归属说明及 SHA256 均在上传前核对；最终下载文件还会从 GitHub 实际下载并校验。
