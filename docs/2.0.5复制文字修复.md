# 2.0.5 复制文字修复

## 故障证据

用户诊断包显示正在运行 2.0.4。2026-10-13 北京时间 22:06:05 和 22:06:07，识别完成后的复制抛出 `COMException`，HResult 为 `0x800401D0`（`CLIPBRD_E_CANT_OPEN`）。堆栈定位到 `System.Windows.Clipboard.Flush` 和 `TextResultViewModel.Copy`。这属于剪贴板写入/持久化争用，不是 OCR 失败。诊断落盘失败数为 0，日志正在更新。

## 改动和文件

| 功能 | 文件 | 结果 |
| --- | --- | --- |

## 验证

本地 Linux 可验证构建和 Core 测试；剪贴板与窗口行为由原生 Windows CI 的 `clipboard-ui` 检查验证。发布包内 `validation/clipboard-ui.log` 和 `validation/validation-desktop.json` 提供该提交的实际结果。检查失败时禁止发布。

## 边界

程序不能强行解除其他软件持有的系统剪贴板锁。持续占用时会明确提示，保留文字并允许再次复制。不会预先清空剪贴板，也不会在失败时显示复制成功。在线翻译、微信发送、图片复制不属于本次修复范围。
