# 2.0.41 工具栏与窗口操作简化

移除截图编辑工具栏里显示 `#FF3B30` 一类十六进制代码的颜色输入框。屏幕选区内编辑和独立编辑窗口共用 `EditorToolbar`，两处一起移除。保留八个色块，点击选择标注颜色；线宽、字号、马赛克和填充设置沿用。此次仅移除工具栏输入框，不删除标注颜色属性和渲染数据。

“移回当前屏幕”从文字工作台标题区移到底部关闭按钮旁，与关闭操作共用轻量、低对比的样式和 32 DIP 点击高度。悬停提示用途，保留键盘焦点和双屏恢复行为；Esc 键帽只属于关闭按钮，不暗示恢复操作有 Esc 快捷键。

包含 2.0.40 的手动长截图改动：向下拖过网页可见正文约 60% 高度即滚动，上移至约 55% 以上暂停，再下移可继续，松开完成，Esc 取消。无需把鼠标拖到网页最底部。
