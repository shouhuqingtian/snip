## 模型及离线边界

两个方向文件合计约 221 MB，在软件“下载/修复模型”中获取，存放于 `%LOCALAPPDATA%\SelfSnip\Models`。首次下载需要网络；模型完成校验后翻译只在 CPU 本地执行，不发送图片或文字。

OCR 使用系统组件；如果缺少中文/英语 OCR 语言组件，软件会提示安装，未安装时不宣称识别成功。请在 Windows 的语言/可选功能设置中补齐所选语言的文字识别组件。

英译中原始模型为 Apache-2.0，中译英原始模型为 CC BY 4.0；转换由 Xenova 提供。归属、转换版本及许可见 `THIRD-PARTY-NOTICES.txt`。模型不嵌入安装包。

## 微信发送：当前外部阻碍

当前机器既没有 Windows 桌面，也没有已登录的微信 4.1.15.12，因此无法确认该版本控件名称/结构和发送图片预览流程。已查阅的公开 wxauto 参考仅声明微信 3.9.X，不能将其当作 4.1.15.12 已验证适配。未复制其实现，也未读取微信数据库或调用私有发送协议。

为完成此项，请在你的 Windows 上：

1. 解压新版便携包，保持微信已登录且窗口可见。
2. 在便携目录的 PowerShell 中运行 `./Snip.exe --wechat-diagnostics`。
3. 点击“读取控件摘要”，可保存脱敏 JSON；输出仅供确认控件结构，不执行点击、搜索或发送。
4. 提供诊断输出或实际错误信息，再补齐目标版本适配并验收。实际联系人及截图必须由用户核对并确认发送。

这一阻碍不影响其他截图编辑功能的开发与试用；微信入口遇到不匹配会明确报错，不会假称已经发送。

## Windows 验收重点

- 多屏负坐标、100%/150% DPI 下选区、画布、文字焦点和工具栏不偏移；图像输出不含 UI。
- 文字 Ctrl+Enter 提交、Esc 取消当前输入；重新调整选区会先提示清除已提交标注。
- 贴纸与各工具移动/缩放/删除/撤销结果一致；长图跨 2048 像素渲染块导出正常。
- 贴图穿透后能通过托盘恢复，退出时没有残留窗口。
- OCR 在语言组件齐备时断网识别；翻译模型下载后断网运行，取消和错误保留原文。
- Chrome/Edge 普通网页自动滚动到尾，长图无重复接缝；无滚动接口、动态内容、失焦或上限均明确停止。
- 微信版本、控件与会话身份逐项核实，再由用户使用受控测试联系人验收发送。
