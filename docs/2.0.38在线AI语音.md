# 2.0.38 在线 AI 语音

## 使用

在原来的“在线设置”点击“AI 语音设置 / 试听”，或在文字工作台“更多设置”打开。保存语音服务、接口协议、完整 API 地址、语音模型、音色/Voice ID、播放速度和默认发音方式。原文、译文及放大阅读窗口的喇叭都会使用该默认方式。工作台也可直接切换“Windows 系统语音 / 在线 AI 语音”，选择后保存，新窗口和重启沿用；翻译默认方式单独保存。

预设 OpenAI、硅基流动、通义千问 Qwen TTS、MiniMax；模型和音色都可以手动填写。可新增多组自定义配置，适配 OpenAI Audio Speech、Qwen 非流式 TTS、MiniMax T2A v2 三种协议。自定义不表示任意厂商接口都能直连，豆包等其他协议需专门适配；克隆、声音上传、WebSocket 实时对话与任意自定义 JSON 不在本轮范围。模型/音色候选以服务商控制台和权限为准。

默认仍为系统语音。在线发音仅在点击喇叭后发送对应原文或译文，不发送截图。“中英试听”只发送界面说明的固定短句，试听不保存草稿。在线请求按服务商计费。原文/译文切换、再次点击、编辑正在朗读的原文、重新处理及关闭窗口都会取消相应播放；关闭设置会取消试听。

长文分段获取音频并顺序播放；一次朗读固定使用开始时的服务和密钥，设置改变不会把后续段落静默发送给另一服务。失败保留文字并提示，不自动重试、切换服务或回退系统语音。需要时由用户手动选择系统语音。音频在内存中处理，不写临时音频文件；每段音频最多 12 MiB，单次合成/读取最多 60 秒，完整朗读保留 20 分钟取消边界。播放速度作用于在线音频，系统语音行为保留。

## 密钥与地域

每组语音配置独立加密保存到当前 Windows 用户下。可选择已保存的翻译配置复用密钥，仅允许相同协议 scheme、域名和端口，且地域须匹配；不会更改翻译服务、模型、密钥和默认翻译方式。不同域名服务须填写独立密钥；换 API 地址不自动沿用独立密钥。清除语音独立密钥不会清除翻译密钥。

通义预设为北京地址；新加坡等地域请同时修改 API 地址并使用对应地域密钥。Qwen 返回的音频下载地址仅允许同源或阿里云 HTTPS 存储地址；下载请求不带 API Key，不跟随重定向。

## 协议参考与边界

- [OpenAI 官方 SDK 请求字段](https://github.com/openai/openai-python/blob/main/src/openai/types/audio/speech_create_params.py)：`input/model/voice/response_format`；本轮音色使用字符串形式。
- [通义千问官方非实时 TTS API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)：`input.text/voice/language_type`，非流式 `output.audio.url`。
- [MiniMax 官方 T2A v2](https://platform.minimaxi.com/docs/api-reference/speech-t2a-http)：`voice_setting`、`audio_setting`、`base_resp` 与 hex 音频；预设 speech-2.8-hd。
- 硅基流动按其 OpenAI Audio Speech 兼容接口接入；没有服务商密钥进行实付费合成，不能把协议替身测试写成所有商用模型、音色或听感均已验收。

## 验证进度

本地 Release 编译 0 警告、0 错误；136 项 Core、47 项在线翻译、17 项在线 OCR、21 项 AI 语音协议/生命周期检查通过。协议检查不发外部请求、不使用实际密钥。[真实 Windows 配置与文字界面回归](https://github.com/shouhuqingtian/snip/actions/runs/38850522660)和[35 张实际 WPF 界面回归](https://github.com/shouhuqingtian/snip/actions/runs/38850525160)通过，包含新 AI 语音普通及窄窗口。原生 WinRT 内存音频流往返通过；界面测试使用可控合成器/播放器检查用户操作，不能当作付费厂商端到端合成或实际听感通过。

界面回归后还将播放器的打开/错误事件注册放在设置音源之前，避免快速打开或报错时漏事件；HTTP 客户端禁用 Cookie，防止保存或转发服务端会话。修改后本地编译及所有协议检查再次通过；正式构建仍会对最终提交运行全部检查。正式安装包结果完成后补充；实际服务可用性与听感需用户填写自己有权限的密钥后试听。

聊天模型不能直接当作语音模型；例如 DeepSeek 文本模型不提供本轮的 TTS 接口。需要选择真正的语音服务和语音模型。

发布检查发现多个工作台切换默认发音方式时显示可能滞后，已增加同步并取消旧播放的回归。2.0.37 构建在打包前主动取消且未发布，最终交付 2.0.38；正式验证以最终提交为准。

[最终多工作台 Windows 回归](https://github.com/shouhuqingtian/snip/actions/runs/38851413532)通过：切换默认发音方式会同步其他工作台的显示，并取消其正在进行的旧语音请求。配置、密钥、试听、现有阅读窗口和原生内存流等检查同时通过。
