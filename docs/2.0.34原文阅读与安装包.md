## 安装

Windows 10 22H2 / Windows 11 x64：先右键旧版托盘→退出，再运行 `SelfSnip-2.0.34-Setup-x64.exe`。默认安装在 `%LOCALAPPDATA%\Programs\SelfSnip`，无需管理员权限，完成后从开始菜单启动；可选桌面快捷方式。设置与模型沿用，之后不要再启动旧便携文件夹里的 EXE。

开机自启仍由“通用设置”自行开启；从便携版迁移后，可在安装版中重新保存自启选项，让路径指向安装目录。发行包尚未代码签名，Windows 可能提示未知发布者。

## 下载地址与大陆网络

第三方地址**不能保证永久存在，也不能保证所有大陆网络直接下载成功**。软件固定修订版本、文件大小及 SHA256，可检查文件完整性，不能保证下载站点长期运营。

| 功能 | 当前来源 | 网络要求 |
| --- | --- | --- |
| 基础词典 | 随 EXE 附带 10 万词 | 无需下载或大模型，仅查词和简单短语。 |
| 系统 OCR | Windows 语言 OCR 组件 | 软件免下载模型；系统需安装对应语言组件。 |
| 增强 OCR，约 31 MiB | 三个模型优先魔搭 `modelscope.cn`，失败尝试固定 GitHub 镜像；字符表来自 GitHub | 魔搭是境内来源，字符表及备用源仍依赖 GitHub，不能承诺全套直连。 |
| 离线翻译，约 951 MB | Hugging Face 的 `unsloth/Hy-MT2-1.8B-GGUF` 固定修订 | 大陆部分网络可能无法访问或速度较慢。 |
| CPU/GPU 推理器，约 20/32 MB | GitHub 的 `ggml-org/llama.cpp` b11612 | 同样不能保证大陆无需代理可达。 |

本次云环境检查模型、CPU 推理器及字符表地址均返回 HTTP 200，魔搭请求未成功建立连接。**这不是大陆运营商实测**，不能据此承诺国内速度或认定魔搭源失效。

下载并校验完成后可断网使用，站点暂时不可用不影响已安装模型。建议备份 `%LOCALAPPDATA%\SelfSnip\Models`（翻译及推理器）和 `%LOCALAPPDATA%\SelfSnip\Ocr`（增强 OCR）。另一台 Windows x64 机器退出软件后可复制到相同位置，使用前仍校验。CPU 和 GPU 支持分别安装；复制模型不等于已有 GPU 支持。不应修改清单哈希或运行不可信的 EXE/DLL。
