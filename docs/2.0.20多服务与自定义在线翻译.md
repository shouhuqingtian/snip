# 2.0.20 多服务与自定义在线翻译

针对单一服务故障导致无法翻译的问题，增加备用服务预设和独立自定义配置。在线方式依然只发送文字，OCR 和离线翻译保持独立。

## 操作

打开主窗口“在线翻译设置”或文字工作台“在线设置”。除 DeepSeek、通义千问，还可选择 OpenAI、智谱 GLM、Moonshot / Kimi、硅基流动。模型框提供候选，也可以直接输入模型名，账户权限、区域和模型存续以服务商控制台为准。

自定义：填写配置名称，点“新增自定义”，填写 OpenAI Chat Completions 兼容地址、模型、密钥，测试后“保存并使用此服务”。同一平台不同账号、多个网关可各存一组，密钥不互相借用。支持删除自定义配置，最多 32 组已保存配置。原有版本 1 设置格式和加密密钥兼容，无需重新输入现有密钥。

切换：选择备用配置并保存，返回原文点“在线翻译”。失败保留原文和已有结果，不自动切换或发送到其他服务。保存不会自动翻译；“测试连接”仅发送固定短句，可能计费。切换会放弃未保存的编辑。

## 修改文件

- `src/Snip.Translation/OnlineTranslationProviders.cs`：六家预设、可编辑模型候选、自定义空白默认值。
- `src/Snip.Translation/OnlineTranslator.cs`：保留兼容聊天补全协议；服务异常/超时提示切换入口，不自动故障转发。
- `src/Snip.Core/OnlineTranslationSettings.cs`：枚举配置元数据和删除单组配置的服务契约。
- `src/Snip.Infrastructure/OnlineTranslationSettingsStore.cs`：保留版本 1 / DPAPI 加密兼容性，支持多组配置、原子删除和数量/长度限制；改变地址不复用密钥。
- `src/Snip.App/ViewModels/OnlineTranslationSettingsViewModel.cs`：新增/删除自定义配置、恢复活动配置、切换和测试时禁止修改配置。
- `src/Snip.App/Views/OnlineTranslationSettingsWindow.xaml`：自定义命名入口、可输入模型框、切换提示、保存并选用按钮、可滚动布局。
- `src/Snip.App/Styles/Theme.xaml`：补齐可编辑下拉框实际输入模板，显示当前模型并允许键入；非编辑下拉框行为保留。
- `src/Snip.App/Services/FeatureHub.cs`：保存备用服务后保留当前文字工作台的在线选择，避免重试意外切回离线。
- `tests/Snip.Translation.Checks/OnlineTranslationChecks.cs`：六家协议、自定义地址/模型、故障不自动转发检查。
- `tests/Snip.Windows.Checks/OnlineSettingsChecks.cs`：真实 Windows DPAPI、旧配置加密块不变、实际 XAML 自定义/模型输入、多组密钥隔离、重启恢复、重复名称、删除及测试取消检查。
- `Directory.Build.props`、`docs/使用说明.md`、`README.md`：版本和交付说明。
