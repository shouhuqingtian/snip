# 2.0.18 三种网页截图与手动长图

网页菜单收敛为“捕捉整个网页”“从当前位置向下捕捉”“手动滚动长截图”。移除容易混淆的静态网页入口：普通区域继续使用现有拖选、复制和 PNG 保存。

## 使用

按截图快捷键框选网页正文，点 ↕，选择“手动滚动长截图”。等待“已采集”提示后用滚轮慢慢向下滚动；到想要的地方停下，点“完成”或 Ctrl+Enter。得到的长图只包含选区宽度，从最初选区到最终停止处，随即进入原有编辑、复制和保存流程。

如果提示对齐失败，先向上回到已采集末尾再慢慢向下滚动。采集中不要移动浏览器、切换窗口或改变显示器布局。控制条不占用截图区域；无处放置控制条时需缩小选区或退出浏览器全屏。此轮实现滚轮驱动，未实现按住鼠标靠近下沿的自动滚动。

## 验证与边界

本地 Release 构建、核心 / 在线协议 / 计算配置检查执行后记录；真实 Windows Chrome 和 UI 检查由交付流水线执行，通过前不发布下载。最终提交、流水线和结果将在交付后补充。

自动 90 秒、手动 5 分钟；最多 160 个已拼接帧、24000 像素高或 6000 万像素。超限停止而不静默截断。复杂嵌套滚动、动态网页、视频、横向移动和太快的整屏跳跃仍有边界；此轮没有声称覆盖所有网页或已经验证用户的双屏硬件。

诊断只记录模式、尺寸、阶段、帧数、位移与匹配信息，不记录键盘输入、截图内容、网页地址或标题。
