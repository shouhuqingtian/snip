# 2.0.61 账号同步与标注线条

## 范围

恢复此前暂停在 `paused-account-sync` 的私有账号功能，接入 2.0.60 图片选字版本；保留 2.0.58 配置迁移。主窗口新增“账号与同步”，注册后两台 Windows 设备登录同一个账号，共用翻译、在线 OCR、AI 语音服务配置、密钥和默认方式。约每 30 秒检查变化，失败退避至最多 5 分钟；可暂停自动同步或手动同步。云端版本比较拒绝过期上传，两边同时变化时需要明确选择方向。

账号密码在客户端经 PBKDF2 派生认证与配置加密用途不同的凭据；服务器仅保存认证哈希和 AES-GCM 加密配置。客户端会话及解密凭据按当前 Windows 用户 DPAPI 保护，下载的模型密钥重新加密。同步不上传截图、OCR 原文、译文或模型文件。快捷键和原文展开仍为设备本地设置，文件迁移继续支持。退出账号不删除本机模型密钥；首版没有密码修改和找回，忘记密码无法解密云端配置。

## 部署

新增同版本 `self-snip-sync-server-2.0.61.zip`：包含 Linux x64 自包含程序、systemd 脚本与单元、Nginx HTTPS location 示例，并保留可选 Docker 部署。不需要数据库和 GPU。目标是用户提供的 2 核 2 GiB Ubuntu x64；尚未登录或部署用户的实际实例。

systemd 服务只监听 `127.0.0.1:5080`，限制 256 MiB / 半核；与现有 HTTPS 网站通过 `/selfsnip/` 反代共存，不修改网站证书、安全组或原有应用。注册由随机邀请码控制。详细安装、首次注册、第二台登录、备份和回退见 [部署说明](../packaging/account-sync/README.md)。实际域名、HTTPS 反代和系统服务需要在用户服务器完成验证。

## 标注

矩形采用随线宽变化的轻微圆角；圆圈/椭圆继续使用抗锯齿矢量轮廓。箭头改为单个实心轮廓，头部按线宽及总长度缩放，短箭头不会出现过大的 V；尾部圆润，头部也参与点击选中。默认线宽仍为 6，保留已有颜色、填充、移动、缩放和撤销。

预览和导出共用渲染路径，没有为长图创建全尺寸超采样缓冲区。绘制边缘属于视觉取舍，不宣称复刻微信私有实现。
