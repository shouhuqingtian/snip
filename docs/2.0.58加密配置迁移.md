# 2.0.58 加密配置迁移

账号登录与服务器自动同步按用户要求暂停，保存在 `paused-account-sync` 分支供后续继续。本版不部署服务器、不添加登录，也不启用后台同步。

## 使用

主窗口点击“配置迁移”。在当前电脑输入并确认 8–256 位迁移密码（建议至少 12 位），点击“导出加密配置”，保存 `.snipconfig` 文件。通过 U 盘或自己的网盘带到家中，在另一台电脑同一入口输入密码，点击“选择文件并预览”，核对服务组数，再点击“导入并应用”。从托盘退出软件并重新启动，使快捷键和全部默认设置生效。密码无法找回，建议与迁移文件分开保管。

导入替换迁移范围内的全部配置，不与本机服务列表合并；可先导出本机配置备份。预览不修改本机，导入前若本机已有新修改则要求重新预览。文字工作台或其他设置窗口仍打开时禁止应用，避免覆盖未保存内容或切换正在使用的密钥。

包含：所有已保存的翻译 / 在线 OCR 服务名称、API 地址、模型、视觉模型、密钥、当前服务；AI 语音服务、协议、模型、音色、速度、独立密钥或复用翻译密钥的引用、默认发音方式；在线 / 离线 / 基础词典及翻译方向、默认 OCR 方式、原文展开状态、截图和贴图快捷键。

不包含：截图、OCR/翻译文本、贴图历史、日志、模型文件、账户会话、安装路径或开机自启。模型需要在另一台电脑单独下载；快捷键是否被其他软件占用仍以目标电脑为准，启动时沿用原有冲突提示。源电脑无法解密的既有密钥不会被绕过保护，须在源电脑重新填写后再导出。

## 加密与失败恢复

迁移文件使用 PBKDF2-SHA256（600,000 次）派生密钥和 AES-256-GCM，每次随机盐和 nonce，认证文件头及密文。明文 JSON 仅短暂存在内存，序列化明文字节及派生密钥使用后清零；不将明文密钥写入临时文件或诊断日志。导入后重新使用目标 Windows 用户的 DPAPI 保护密钥，解决直接复制原设置 JSON 无法跨电脑解密的问题。迁移密码不保存到设置，操作后清空密码框。托管字符串受运行时垃圾回收管理，无法保证内存字符串原地清零。

导入先验证格式、版本、大小、服务数量、协议、地址和设置范围，再生成目标电脑受保护的文件。密码错误或认证失败不返回部分配置。应用前创建持久回滚记录，仅保存原有 DPAPI 文件和非秘密偏好；替换中断时恢复原文件，暂时受锁无法恢复则保留记录，下次启动先恢复成功再读取设置。关闭迁移窗口取消迟到结果，不自动应用。文件密码不能抵御弱密码被离线猜测，应使用足够长且独立的密码。
