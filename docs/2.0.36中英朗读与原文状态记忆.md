# 2.0.36 中英朗读与原文状态记忆

## 使用方式

文字工作台的原文和译文各有一个喇叭。点击读取对应完整文字，自动按实际内容选择中文或英语系统语音；再次点击停止，点击另一侧会停止上一侧并切换。原文和译文的放大阅读窗口也提供相同入口。在线翻译、离线模型和基础词典均可使用，只有 OCR 结果时也可朗读原文。

朗读使用已安装的 Windows 系统语音，不调用在线模型、不发送文字、不生成临时音频文件；只在点击后创建合成器和播放器，停止/完成后释放。缺少对应中英语音时保留文字，并提示在 Windows“时间和语言 → 语音”中添加。长文分段合成，保留已有取消、长度和超时限制。中英混排按主要语言选择一个语音，不提供逐词语言切换。

“展开原文 / 收起原文”点击后自动保存最后一次选择，新截图和重启后沿用。该设置独立存储，不修改在线/离线/基础翻译默认设置，也不保存原文或译文。没有选择过时保留原先首次翻译后收起的行为；仅识别文字、没有译文时始终显示原文。重新识别及后续翻译不会覆盖用户保存的选择。保存失败时本窗口仍可展开/收起并显示原因。
