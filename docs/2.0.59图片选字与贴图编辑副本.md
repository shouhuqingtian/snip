# 2.0.59 图片选字与贴图编辑副本

## 行为

独立编辑窗口底部增加“选取文字”。点击后才在本机识别当前合成图片，在原图位置直接拖选文字，用 Ctrl+C、底部“复制文字”或右键菜单复制；Ctrl+A 全选，双击选择识别词块，Esc 或再次点击选字返回标注。选择标注工具（即使原来已选中该工具）也会退出选字。选字模式中鼠标中键复制选中文字；工具栏绿色完成按钮仍复制图片并完成编辑。

缩放和滚动共用原始像素坐标；拖选接近视口边缘时自动滚动。高亮只属于预览层，不写入图片、不改变导出尺寸、不加入撤销历史。没有修改图片时可复用本次识别结果；编辑、撤销、重做、输入标注或马赛克使缓存失效。识别、PNG 编码和文字几何建立均在后台，超时、取消、模式退出和窗口关闭阻止迟到结果重新出现。没有常驻识别或空闲轮询任务。

贴图右键增加“编辑（副本）…”。打开独立编辑窗口，支持相同选字功能；原贴图、缩放与位置保留，不被覆盖。编辑后可复制、保存 PNG 或重新钉为另一张图，关闭原贴图不会关闭编辑副本。

## OCR 和边界

直接选字只用本机 OCR，不隐式上传截图。沿用本机识别偏好：系统识别使用 Windows 语言组件；已经下载并选择的增强离线识别使用现有模型；在线 OCR 默认在直接选字时使用系统识别。在线视觉模型通常不返回可靠词坐标，因此继续在文字工作台使用，不作为图片上的可选择文字层。没有系统语言组件时可先在 Windows 安装中文 / 英文 OCR，或在文字工作台设置并下载增强离线识别。

系统 OCR 新增返回原始词框，并在分块和小截图重试时映射回原图。词框内字符和增强引擎仅有文本块框时，字符位置按字形宽度估算；不承诺与原生网页 DOM 或每个字的实际排版完全一致。横排中英截图为主要使用场景，倾斜、竖排、复杂表格或识别错误仍受 OCR 能力影响，可使用文字工作台修正。

识别输入包含当前标注和马赛克，不读取未合成的隐藏原文。与马赛克交叉的原生词框明确剔除；只有整行框的引擎保守剔除交叉文本块，避免上下文猜测带出遮挡词。选字遵循源图行列次序，保留已有空格 / 换行，不依赖引擎返回顺序。超大文字结果明确要求分段，避免创建大量逐字 UI 控件。
