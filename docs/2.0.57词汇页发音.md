# 2.0.57 词汇页发音

## 行为

原问题：翻译结果切换到“读音与词汇”后，喇叭仍读取整段译文。现在“完整译文”朗读译文，“读音与词汇”朗读本次结果中列出的英文词汇，按显示顺序、最多 8 项，以短暂停顿分隔。音标、词性、释义、拼音和页脚说明不参与朗读。只有拼音而没有英文词汇时，该页隐藏结果喇叭，不偷偷改读译文或沿用上次词汇。

放大阅读与工作台共用当前标签页和播放状态；切换标签会停止上一段结果朗读，再次点击喇叭才读新内容。原文朗读不受结果标签切换影响。系统语音和已配置的在线 AI 语音均共用这套选择规则，切换标签本身不发送请求，不重复翻译。

## 修改文件

- `src/Snip.App/ViewModels/TextResultViewModel.cs`：保留本次响应的结构化英文词汇，按标签选择发音文本、按钮标签与可用性；标签变化取消旧的结果播放；新响应替换词汇，失败保留已有结果。
- `src/Snip.App/Views/TranslationReadingWindow.xaml`：放大阅读绑定工作台同一个标签状态，确保可见内容与发音一致。
- `tests/Snip.Windows.Checks/VocabularySpeechChecks.cs`：通过实际 WPF 标签和按钮验证发送给语音服务的内容、语言、取消令牌，以及拼音无词汇、新响应和关闭窗口。
- `tests/Snip.Windows.Checks/TextReadingChecks.cs`：接入回归，既有完整译文播放测试显式选择完整译文标签。
- `Directory.Build.props`、`docs/使用说明.md`：版本与操作说明。
