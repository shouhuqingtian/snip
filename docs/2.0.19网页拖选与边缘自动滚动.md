# 2.0.19 网页拖选与边缘自动滚动

第三个网页入口改为“捕捉选定区域”：按住左键拖选，碰到网页下沿自动滚动，松开即输出所选范围。整个网页和从当前位置向下两个入口继续保留。

此前手动模式把左键事件交给浏览器，无法实现跨屏拖选；拖动会触发浏览器的文字选择。此次接管截图手势，使用程序控制的小步滚动和稳定画面，采集正文视口后按文档坐标裁剪。用户截图中的对齐失败尚不能仅凭截图确定全部原因，新回归覆盖已选中的蓝色文字、固定侧栏和底栏。

## 使用

框选网页正文后点击 ↕ → 捕捉选定区域；等待提示后重新按住左键拖出最终选区。碰到网页下沿时页面自动向下滚；到所需终点松开即可，Esc 取消。蓝色文字不是截图选区，绿色边框才是。

## 验证与边界

本地编译与 Core / 在线协议 / 计算配置检查通过后，执行真实 Windows Chrome 及完整桌面回归；通过前不提供发布包。最终提交、检查结果和下载核对将在交付时补充。

不依赖安装浏览器扩展，仍采用桌面截图与滚动拼接；本轮对齐的是拖选交互，并未宣称具备 FireShot 的全部网页 / PDF / 标签页能力。动态视频、复杂嵌套滚动或无法确定移动位置的纯空白区域可能停止。原有 5 分钟、160 个拼接帧、24000 像素及 6000 万像素上限继续有效；用户双屏布局仍需实机验证。

诊断只记录尺寸、帧数、位移、匹配信息和阶段；不会记录拖选所在网页内容、地址、窗口标题、键盘字符或截图。
