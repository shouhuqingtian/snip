# 2.0.26 贴图同步、恢复与快捷键

## 原因与行为

旧贴图管理窗口只在构造时遍历一次当前窗口列表；先打开空管理窗口再钉图时，新增贴图没有对应行，空状态也不刷新。已有贴图关闭后只从列表删除，没有恢复记录。

本轮采用实时可观察列表与共享的管理 ViewModel。已经打开的管理窗口会立即显示新增贴图、缩略图、正在显示 / 已关闭状态及数量；重复打开会定位原管理窗口。截图选区和独立编辑器继续使用同一个 PinManager。

## 使用

1. 截图后点击“钉在桌面”。从托盘打开“贴图管理”，点击缩略图或“定位”找到相应贴图。
2. 贴图可拖动、滚轮缩放、右键调整透明度和鼠标穿透。Esc 或“关闭”关闭贴图后，管理列表保留“已关闭 · 可恢复”记录。
3. “恢复上一张”恢复最近关闭的一张；也可在任意关闭记录上点击“恢复”。复用原图，恢复位置、大小和透明度，恢复后启用鼠标交互。原显示器已移走或窗口位置不可见时，按物理像素放回可见显示器范围。
4. “上一张 / 下一张”在正在显示的贴图之间循环定位，并恢复鼠标交互；其他贴图保持可见。只有一张时定位该张，没有显示贴图时可先“恢复上一张”。
5. 点击“快捷键设置”，分别配置恢复、上一张、下一张的全局组合键。默认不占用新组合，可自行设置，例如 Ctrl+Alt+F6 / F7 / F8。直接按 Delete 或 Backspace 清除某项，保存后立即生效，重启后保留快捷键配置。
6. 贴图快捷键不能重复；与截图或其他软件冲突时提示并尝试恢复原贴图绑定，截图快捷键单独保留。配置写入失败时回退原贴图绑定。

## 会话与资源

按用户确认，图片仅在本次运行中恢复，不额外落盘；退出软件会清空图片记录。快捷键保存到当前用户的 `pin-hotkeys.json`，只包含按键配置。

已关闭图片最多保留最近 10 张，按宽 × 高 × 4 的保守估计限制在 64 MiB 内，超出淘汰旧记录。单张超过缓存预算时关闭后不保留，并显示原因；正在显示的贴图不受该历史预算淘汰。“移除记录”删除某张已关闭记录；“清空关闭记录”保留正在显示的贴图。图片在显示窗口与记录之间共享冻结位图，恢复不重新截图、编码或复制整张原图。

## 同轮发现的复制阻塞

贴图与快捷键原生检查通过后，完整回归在持续剪贴板锁场景停于“等待复制重试结果”，界面线程未能返回结果。旧 WinForms SetDataObject 即使关闭框架内部重试，仍涉及同步 OLE 数据对象 / Flush 调用。本轮改用 Win32 即时 CF_UNICODETEXT：先准备全局可移动内存，成功获得剪贴板后才替换内容，成功提交后由 Windows 接管内存；失败与取消时释放未提交内存。保留原有七次异步延迟与错误语义，测试继续验证 Unicode / 多行、持续占用失败、释放后重试、关闭取消及发布进程退出后的内容保留。

本地 Release 编译 0 警告、0 错误，108 项 Core 与 39 项在线协议检查通过。独立 PowerShell 模拟验证：FailFast 在第一项失败时保留失败记录并停止；全部成功时仍执行所有检查。Windows 原生贴图、全局按键和完整回归正在验证，发布前补充实际结果。显示器物理坐标恢复仍需用户实机多屏组合验收。
