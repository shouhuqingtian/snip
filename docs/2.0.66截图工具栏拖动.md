# 2.0.66 截图工具栏拖动

截图工具栏以前始终按选区自动定位，覆盖要阅读的内容后无法手动挪开。本版在截图工具栏左侧增加小拖动柄，也可拖动工具栏的空白、边距或文字标签。拖过系统拖动阈值后移动，松手后在本次截图中保持位置；继续使用标注工具、颜色或线宽时不跳回。重新选择区域或开始新截图恢复自动定位。

工具栏仍属于当前截图屏幕的覆盖层，可在本屏幕范围内移动；靠边会限制在屏幕内，提示条继续避让。不会变更截图选区、生成标注或将工具栏写进图片。独立编辑窗口保持原有固定工具栏。

按钮、颜色、复选框、下拉框和文字输入保留原操作，不从这些控件启动工具栏移动。拖动未结束时 Enter / 中键不复制，Esc 仅撤销本次工具栏移动；松手后 Enter / 中键继续复制截图。鼠标捕获丢失、窗口失活或关闭会结束移动并释放捕获。

## 修改文件

- `SelectionWindow.cs`：空白处拖动、当前位置保持、拖动取消/捕获生命周期、边界限制和提示避让。
- `EditorToolbar.cs`、`UiIcon.cs`：只在截图覆盖层显示的矢量拖动柄；独立窗口不额外显示。
- `ToolbarDragChecks.cs`、Windows 检查入口及验证脚本：真实 Win32 鼠标键盘回归，控件操作、捕获丢失、重新选区、缩放后移动和复制原始像素。
- 定向与公开预览检查工作流：增加工具栏拖动场景与公开夹具图。
