# 2.0.50 网页弹层与粗粒度选区

修复网页弹层、弹层内 iframe 仍误选底层页面矩形的问题，并按用户反馈把自动选区改为较大区域：页面主体、弹窗、面板、列表和工具栏；不再逐个框选按钮、输入框、单元格、列表行。网页弹窗内嵌的文档/面板优先归为当前整个弹窗，不逐层细分。

## 修改文件

| 文件 | 修改 |
| --- | --- |
| `src/Snip.Infrastructure/BrowserHoverHitTest.cs` | 在指定 Chromium 窗口上调用辅助功能命中检测，沿实际命中的父链选容器，优先当前最近的弹窗，避免截图遮罩以及被网页弹层遮挡的兄弟节点；不读取文字、名称或网页地址。 |
| `src/Snip.Infrastructure/HoverRegionWorker.cs` | Chromium 优先使用命中路径，失败保留原生大区域；其他窗口保留 UI Automation，跳过原子控件，内部候选最小 160×96 DIP，随目标窗口 DPI 换算。 |
| `tests/Snip.Windows.Checks/SmartBrowserChecks.cs` | 实际 Chrome 公开页面复现底层行误选；检查 CSS 弹层、iframe 面板/空白处归属当前弹窗和多层弹窗，以及 Enter 冻结图像素；第 42 张预览；测试 Chrome 独立输出管道和启动失败清理，避免残留浏览器拖住检查。 |
| `tests/Snip.Windows.Checks/HoverRegionChecks.cs` | 普通 WPF 工具栏、输入面板、完整列表、面板的大区域选择；小按钮/字段/行不再独立框选；继续验证实际快捷键、Enter、超时、迟到保护、辅助进程回收与取消；90 秒原生检查期限和无内存转储的线程栈。 |
| `Directory.Build.props`、`docs/使用说明.md` | 版本与操作说明。 |
