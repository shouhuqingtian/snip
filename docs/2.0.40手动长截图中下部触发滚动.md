# 2.0.40 手动长截图：中下部触发滚动

## 使用变化

2.0.39 提高了滚动采集速度，但仍需要拖到网页最底部 24 个物理像素内才触发，用户需要把鼠标拉得太远。本次把触发区域改为相对网页**可见正文区域**的比例：

1. 按住左键从起点向下拖选，到可见正文约 60% 高度即自动向下滚动，无需到屏幕底部。
2. 保持在中下部继续滚动；向上移到约 55% 以上暂停。55%～60% 为缓冲带，避免轻微抖动造成反复启停。
3. 回到约 60% 以下可继续滚动；松开左键生成所选范围，Esc 取消。

首次只按住或水平拖动，不立即触发向下滚动；至少向下拖动 8 个物理像素后才启用，防止在中下部开始普通选区时突然滚页。已滚动后可重新回到触发区继续，即使光标屏幕位置高于初始选区起点。边界比例基于物理像素计算，适应窗口大小和 DPI。

上移或松开时，已经发出的那一轮滚动会等待稳定并拼接完成，再暂停或裁剪；不会丢弃正在采集的末段。2.0.39 的步长调整、稳定检测、严格重叠匹配、控制条/选框排除和资源释放保留。菜单、准备提示及拖选状态同步更新为新的操作方式。
