# 2.0.43 默认选区直接回车复制

## 行为

按 Ctrl+Alt+A（或自定义截图快捷键）后，立即初始化鼠标所在窗口的预选范围。不用移动鼠标或点击确认，直接按 Enter 就复制当前高亮区域并退出截图。移动鼠标悬停到其他窗口后，Enter 复制新的高亮区域。

单击窗口或拖动框选仍进入标注；在编辑中按 Enter 或绿色对勾复制当前截图及标注。正在按住鼠标拖选时忽略 Enter，避免复制尚未完成的范围。没有可预选窗口时保留手动框选，不会擅自复制全屏；Esc 取消不会改写剪贴板。复制未完成时重复按 Enter 不会发起并行导出。

画面使用进入截图时的冻结桌面图，不重新采集，不会带入遮罩、工具条、选择边框或放大镜。多屏使用同一物理像素选区，不改变已有屏幕坐标处理。

## 原因与修改文件

旧版自动高亮范围只保存在每个屏幕的绘制控件中，键盘确认只检查已提交的选区；未移动鼠标时也没有初始化预选。此外第一次确认在创建编辑器后就返回，未继续复制。

| 文件 | 修改 |
| --- | --- |
| `src/Snip.App/ViewModels/SelectionViewModel.cs` | 统一预选与当前实际显示范围；保留预选和已确认范围的区别，避免影响鼠标重选及拖动。 |
| `src/Snip.App/Services/SelectionSession.cs` | 显示覆盖层前初始化预选；Enter 提交高亮范围、建立编辑器后完成复制；保持布局变化检查，阻止并行确认。 |
| `src/Snip.App/Views/SelectionWindow.cs` | 绘制与键盘共享同一范围；初始化放大镜坐标；提示 Enter 直接复制、单击进入标注。 |
| `tests/Snip.Windows.Checks/SelectionChecks.cs`、`HotkeyChecks.cs` | 真实 RegisterHotKey、原生键鼠、实际 WPF 覆盖层和图片剪贴板检查，逐像素核对冻结桌面裁剪；覆盖悬停切换、手动重选、拖选中回车、Esc、无候选和重复回车。 |
| `.github/workflows/windows-targeted.yml` | 可单独运行热键及截图确认回归；完整桌面检查也通过原有 hotkey 组执行，不跳过发布检查。 |
| `Directory.Build.props`、`docs/使用说明.md` | 更新版本与操作说明。 |
