# 自用截图 2.0 系列使用说明

## 2.0.6 统一界面

主界面、选区工具栏、独立编辑器、文字识别/翻译、文字输入、贴纸、分享和贴图管理统一采用浅色卡片与绿色主操作。截图工具栏换为矢量图标，常用颜色可直接点击色点；自定义颜色仍可填写十六进制值。具体修改文件见《2.0.6界面美化》。下载页另有 `ui-previews.zip`，内含使用合成图片渲染的真实 Windows 窗口预览。

## 2.0.5 复制文字修复

“复制文字”和“复制译文”会显示正在复制、占用重试、复制成功或失败的独立提示。剪贴板短暂被其他软件占用时，约两秒内自动重试；等待期间窗口仍可操作。持续占用时保留截图和文字，稍后再点复制即可；也可在文字框中选中内容按 Ctrl+C。没有文字时复制按钮禁用。复制成功后关闭结果窗口或退出软件，文字仍保留在系统剪贴板。

诊断日志新增 `text-clipboard` 操作，记录成功、重试、失败和关闭取消；不记录原文或译文。修改文件和验证说明见《2.0.5复制文字修复》。

## 2.0.4 文字识别与离线翻译

截图后点击工具栏“文”或“译”，结束全屏选区并打开独立结果面板。左侧是截图预览，右侧是可修改和复制的识别文字；“译”会自动识别后翻译，保留原文和译文。关闭编辑窗口不会关闭识别结果。识别没有结果、缺少语言组件或翻译模型时，面板保留截图并说明原因；可以切换识别语言、重新识别、下载/修复模型后再次翻译。

2.0.4 修复结果窗口进度绑定导致整个软件退出的问题，并补充真实结果窗口和选区工具栏回归。运行日志是 `%LOCALAPPDATA%\SelfSnip\Logs\events.jsonl`；便携包里的 `validation/*.log` 属于构建检查记录，不会随使用更新。具体原因和修改文件见《2.0.4文字识别与翻译窗口修复》。

## 2.0.3 诊断与问题反馈

测试便携版在 GitHub Releases 的“测试便携版”条目下载，解压后运行 Snip.exe。先从托盘退出旧版，在线密钥和快捷键设置保留；2.0.14 离线翻译改为 Hy-MT2，旧 OPUS 模型需重新下载新模型。版本和源码提交记录在 build-info.json 中；原生检查结果在 validation/validation-desktop.json，Passed/Failed/Unrun 分开记录。

遇到问题后，从主窗口点击 **导出诊断包…**，或右键托盘选择同名菜单，选一个位置保存 ZIP。反馈“进行了什么操作、出现什么现象”并附上诊断包，可减少反复询问系统信息。窗口无法操作时可重启应用后导出，轮转日志会保留近期记录。

诊断包包含软件完整版本、Windows/.NET、处理器数量、显示器尺寸/DPI、Chrome/Edge 安装版本、操作阶段、耗时及脱敏异常类型/HResult/堆栈。长截图另记录视口尺寸、滚轮单位、位移和重叠匹配误差。诊断不会自动上传，也不包含截图、OCR 原文、译文、网页地址、窗口标题、联系人、用户名或密钥。

日志存放于 `%LOCALAPPDATA%\SelfSnip\Logs`，后台写入，默认最多 5 个文件、每个 2 MiB。写入失败仍保留最近 200 条内存记录，导出文件会显示丢弃数和写入失败数。

也可使用命令行导出：

```powershell
./Snip.exe --export-diagnostics "$env:USERPROFILE\Desktop\自用截图-诊断.zip"
```

命令完成后退出（成功退出码 0），可用于自动验证或应用主界面无法打开时读取已有日志。导出的临时文件在失败/取消时清理，已有目标文件只在完整 ZIP 生成后替换。

## 启动与截图

运行于 Windows 10 22H2 / Windows 11 x64。便携版解压后运行 `Snip.exe`；安装版按当前用户安装。无需单独安装 .NET。首次启动部分原生组件会解压到用户临时目录。

软件常驻系统托盘，双击图标打开主窗口。默认按 **Ctrl+Alt+A** 或使用托盘开始截图；主窗口点击快捷键旁的“修改”，按下新组合并保存即可立即生效，重启后保留。新组合冲突时保留原快捷键；“恢复默认”需再点击保存。主窗口关闭后仍在托盘运行，退出使用托盘菜单。

进入截图后：立即预选鼠标所在窗口，直接按 **Enter** 可复制当前高亮区域并退出，无需先点击；移动鼠标可以切换预选窗口。单击窗口可进入标注，或左键拖动重新选择区域。选区支持多屏及不同缩放比例。松开鼠标后直接显示浮动工具栏并在选区内编辑。方向键在没有标注/文字输入时按实际像素微调选区。使用“重新调整选区”可移动边缘或拖动新区域，有标注时会先提示清除。

放大镜显示鼠标位置的原始画面细节；图片采集的是进入截图前的静态桌面。普通区域截图会保留当前可见的软件自身窗口，快捷键及主窗口“开始截图”都支持截取主窗口、文字工作台、编辑窗口及贴图；默认预选也包含它们。显示器间没有屏幕的区域为黑色。快捷键冲突、显示器布局改变会明确提示。

## 贴图

贴图可拖动位置，滚轮缩放，右键复制、保存、调整透明度、开启鼠标穿透或关闭。Esc 关闭当前可交互贴图。

开启穿透后不能直接点击贴图；使用托盘“贴图管理”恢复交互或关闭。软件退出时关闭所有贴图。

## 离线 OCR 与翻译

OCR 使用 Windows 文字识别组件。选择中文或英语语言进行识别；未安装组件时软件提示安装。请在系统的语言/可选功能中补齐对应 OCR 组件。

翻译首次使用点击“下载 / 修复模型”，唯一模型为 Hy-MT2-1.8B Q3_K_M，中英双向共用约 951 MB 模型，另下载约 20 MB 的 llama.cpp CPU 推理器。模型来自 Hugging Face、推理器来自官方 GitHub，版本及模型/压缩包/可执行文件/依赖库 SHA256 固定，下载完成后存放在 `%LOCALAPPDATA%\SelfSnip\Models`。安装/模型下载需要网络；模型齐备后识别与翻译在本机执行，不上传截图和原文。

OCR 原文可修正；2.0.23 起默认自动判断中英方向，每次翻译根据当前原文选择中文译英文、英文译中文，也保留手动指定方向供混合文本使用。原文和译文各有复制按钮。模型缺失、网络失败、取消或识别不到文字都有状态提示。模型是专业翻译用途，仍应核对 OCR 原文和重要术语。单次翻译最多 12000 字符，内部按段落分段并检查实际分词长度，超出上下文或生成上限会提示缩短原文，不返回静默截断的译文。

第三方模型及组件许可见随包的 `THIRD-PARTY-NOTICES.txt`。

Windows CPU 推理器需要微软 Visual C++ 2015–2022 x64 运行库。系统缺少时，文字工作台显示“微软官网下载”入口；从微软官网下载安装后重启软件。该组件不是 Python 或额外模型，通常已随其他桌面软件安装。运行库过旧导致启动失败时也应更新。

## 浏览器长截图（2.0.19）

先在 Chrome/Edge 普通网页框选正文区域，点 ↕。菜单只有三个入口：

1. **捕捉整个网页**：自动使用浏览器正文视口，从页面顶部采集到页尾。
2. **从当前位置向下捕捉**：自动使用正文视口，从当前滚动位置采集到页尾；不会回到顶部。已经在页尾或页面无需滚动时返回当前视口。
3. **捕捉选定区域**：进入模式后重新按住鼠标左键，从需要的网页内容起点拖到终点。拖到网页下沿时会自动向下滚动，继续扩展选区；指针移离下沿就停止继续滚动。**松开左键即生成长图**，只输出拖选范围的宽度和长度；无需滚轮或再点完成。不碰下沿就是普通静态选区。**Esc** 或“取消”放弃。

选区拖选期间，程序会接管左键拖动，浏览器不会同时选中文字。绿色边框表示当前可见选区，每次实际截图前会隐藏该边框；完成 / 取消控制条放在正文视口之外。指针越过正文下沿时，会将滚轮输入送入目标浏览器正文并立即恢复指针原位置，选区不会跟着程序输入改变，也不会滚动鼠标下的其他窗口。松开时会等待最后一步滚动稳定后完成。

初次框选用于定位浏览器；在第三个模式内重新拖选最终所需范围。程序采集完整正文视口后按网页坐标裁剪，进入模式前已选中的蓝色文字会保留在截图中。采集从当前页面位置开始；不主动回顶部，也不恢复原位置。请为正文外的控制条保留空间；浏览器全屏时可先退出全屏。

采集过程中不要切换窗口、移动或调整浏览器，也不要改变显示器布局；Esc 取消。自动模式通过原生滚轮采集，不要求提供辅助功能滚动接口；可用时会读取滚动位置用于校验并恢复原位置，否则停留在采集终点。复杂嵌套列表、动态布局、横向滚动和跳过整屏的快速滚动不保证可拼接。

自动模式上限 90 秒；手动模式上限 5 分钟。两者最多 160 个已拼接帧、24000 像素高或 6000 万像素；超限会停止，请分段截图。拖选模式只在靠近下沿自动滚动时采集，等待用户开始拖选或静止在中间时不持续截图。普通静态区域截图继续使用原本的拖选、复制或保存操作，不再单独出现在网页菜单。

## Windows 系统分享与羊图标

截图选区和独立编辑器点击分享箭头，打开独立截图预览并自动呼出 Windows 系统分享面板。选择系统列出的应用或附近设备，再按对应应用的流程发送；目标列表由 Windows 和已安装应用决定。微信是否出现在列表取决于微信是否注册了 Windows 分享目标，软件不再自动搜索微信联系人或点击发送。

关闭系统面板后可点击“打开系统分享”重试。系统分享不可用时，预览窗口保留截图和错误提示；“复制图片”可粘贴到聊天窗口，“保存 PNG”可用于手动转发。分享使用 PNG 文件和图片格式；为允许目标应用稍后读取，会在 `%LOCALAPPDATA%\SelfSnip\ShareCache` 临时保留图片，下次分享时清理超过 24 小时的缓存。无需缓存时可退出软件后手动清空该目录。

托盘、窗口标题栏和 EXE 均采用绿色底白色羊图标。右键托盘可截图、打开主窗口、管理贴图、导出诊断和退出；双击打开主窗口。如果通知区域未显示图标，检查任务栏的隐藏图标列表。

## 2.0.1 网页截图与处理状态

先退出旧版托盘进程再更新。2.0.1 曾提供四种网页入口；2.0.18 已改为上面的三种，旧“可见网页 / 选定区域”静态入口已移除。采集期间不要切换窗口，Esc 可取消。没有滚动位置接口时网页留在采集结束位置。

OCR 和翻译在后台处理，显示阶段、耗时和进度，可点击取消；OCR 超过 45 秒、翻译超过 90 秒会停止等待并保留已有结果。在线密钥和快捷键设置保留；2.0.14 离线翻译已改为 Hy-MT2，旧 OPUS 模型不再使用，需要下载新模型。

## 2.0.2 采集界面

长截图期间会隐藏原有编辑窗口和置顶贴图，采集结束后恢复。自动模式不显示浮动进度窗；2.0.18 手动模式在选区外显示完成 / 取消控制条。托盘提示显示采集状态。按 Esc 取消；打开托盘菜单也会先取消，避免菜单被拍进长图。白底文章、内嵌图片和固定底栏已增加专门的真实 Chrome 回归检查。


## 2.0.7 编辑性能

普通标注使用矢量预览，马赛克只计算对应小区域；未加标注的截图直接复用原图。关闭选区时清理编辑画布的事件订阅，并解除对旧选区窗口的引用，避免独立编辑器继续保留整张多屏桌面截图。

完全离线的中英翻译需要本地模型。Windows OCR 语言组件负责文字识别，并不提供通用中英翻译。2.0.14 使用已校验的 Hy-MT2 专业翻译模型，不联网传输翻译内容；新模型安装一次后即可断网使用。CPU 默认两线程，只在翻译期间加载，完成、取消或关闭结果窗口后回收进程与模型内存。性能优化详情和 Windows 对比记录见《2.0.7编辑性能优化》。


## 2.0.9 双屏窗口与关闭

普通窗口打开时按鼠标所在显示器的实际 DPI 和工作区调整大小及位置；有父窗口的对话框使用父窗口所在显示器。窗口移动跨屏、更换分辨率/缩放、拔掉显示器后，会将超出工作区的窗口调整回可见位置；全屏选区和置顶贴图不使用此逻辑。

文字识别/翻译结果窗口支持 Esc 和“关闭 Esc”按钮，正在识别、翻译或下载时也能关闭并取消任务。顶部还有“移回当前屏幕”；小屏幕和较高缩放下，正文区域可以滚动，关闭按钮始终留在滚动区之外。完整修改及验证记录见《2.0.9双屏窗口与关闭修复》。


## 2.0.10 OCR 空结果与小截图

识别语言默认“自动（中英）”：尝试已安装的中文组件，空结果再尝试英语，最多两个语言；只有一种组件时使用现有组件。手动选择中文、英语或其他语言时会保留该选择。成功状态显示实际识别语言；未安装英语 OCR 时会给出 Windows 语言组件安装提示。这与翻译模型下载是不同的功能。

Windows OCR 首次返回空结果且截图短边小于 64 像素时，会在限定像素数内放大 2～4 倍、增加白色边缘后重试一次；识别坐标换算回原图。正常结果及大截图直接保留原处理路径，全部在本机执行。

如果英文单词截图仍为空，先确认 Windows 安装了英语文字识别组件，再选 en-US 重新识别。截取文字时尽量保留少量边缘；预览放大看起来很大，并不意味着原始截图的字形像素足够。严重模糊、特殊字体或品牌标识不能保证识别。

| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |

| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |

模型下拉框可直接输入任意模型名称，候选仅供参考，以服务商控制台的实际权限和可用模型为准。自定义接口：输入配置名称 → “新增自定义” → 填写 API 地址、模型和密钥 → “测试连接” → “保存并使用此服务”。可以保存多组网关或同一平台的不同账号，每组密钥独立；不再使用的自定义配置可以删除。自定义接口须兼容 OpenAI Chat Completions 和 Bearer API Key；不直接支持 Claude/Gemini 原生协议，可使用提供兼容协议的网关。

服务故障时，打开“在线设置”，选择已有备用配置并点击“保存并使用此服务”；返回文字工作台，选择“在线大模型”并点“在线翻译”重试。原文和已有译文保留，无需重新截图。不会自动把原文发给其他平台。切换选择会放弃未保存的修改，保存不会自动发起翻译。

地址可以填写基础地址或完整 `/chat/completions` 地址，模型名称可修改。通义千问的密钥、模型权限与服务地域须匹配；使用国际地域时根据服务商文档修改地址。当前接入聊天补全协议，不接入网页端会员登录。

“测试连接”会向所选服务发送固定 Hello world 短句，可能计费；不会自动保存。保存后在文字工作台选择“在线大模型”，再点击“在线翻译”。需要记住在线模式时，在文字工作台点击“保存为默认”，或在主窗口“通用设置”中保存默认翻译方式。默认仍为离线；在线模式无需下载翻译模型。

OCR 继续离线。在线翻译只发送识别后的文字，不上传截图；文字、密钥、地址与服务原始错误正文不会写入诊断日志。密钥用 Windows 当前用户 DPAPI 加密，位于 `%LOCALAPPDATA%\SelfSnip\online-translation.json`，不进入诊断包或源码。更换同一服务地址时需要重新填写密钥，以免把旧凭据发给新服务器；清除当前密钥会切回离线默认模式。

在线请求最多等待 60 秒，可取消或关闭窗口；错误保留原文和已有译文。模型质量、额度、费用及服务可用性由提供方决定。详细改动和验证见《2.0.11在线大模型翻译》。

## 默认文字识别（2.0.15）

OCR 使用 Windows 本地文字识别组件，与翻译独立。不填写 DeepSeek/通义千问密钥、不下载 Hy-MT2 翻译模型，也能点击“离线文字识别”查看截图和可修改、可复制的识别文字。点击“文字识别 / 中英翻译”时，若所选翻译方式尚不可用，默认只显示 OCR 结果，提示配置方式，不报缺模型错误、不自动下载模型、不发送文字到在线服务。

Windows 必须安装相应 OCR 语言组件。缺少时窗口保留截图并提示在 Windows 设置→语言和区域中添加中文/英语及文字识别组件。这项 Windows 组件依赖与软件的离线翻译模型下载无关。

## 通用 GPU 离线翻译（2.0.16）

文字工作台新增“离线计算”选择，保存后重启仍保留：

- 自动：已安装 GPU 支持且存在兼容设备时优先 GPU，其他情况使用 CPU。
- 仅 CPU：不进行 GPU 检测，不启用 GPU 计算。
- 优先 GPU：尝试 GPU，无兼容设备、显存不足或后端失败时回退 CPU。

先安装离线翻译模型，再点击“下载 / 修复 GPU 支持”。GPU 支持只增加约 32 MB 官方 Vulkan 运行库（解压后约 80 MB），不重新下载约 951 MB 模型。NVIDIA、AMD、Intel 显卡须有支持 Vulkan 的驱动；无需安装 CUDA Toolkit。不是所有旧显卡都兼容。设备检测暂设至少 1536 MiB 可用显存/共享内存，推荐有 2 GB 以上可用空间；实际加载失败仍会回退 CPU。核显可能不比 CPU 快。

状态栏显示本次实际计算方式；仅在确认模型层被加载到 GPU 后显示 GPU。完成、取消或关闭窗口后关闭工作进程并释放 GPU/CPU 模型资源，不在托盘闲置时常驻模型。首次 GPU 启动可能因驱动编译着色器较慢；模型加载超过 30 秒会停止并尝试 CPU，整次翻译仍有 90 秒截止。

在线翻译由服务商计算，不使用本机 GPU；在线模式下本地计算选择和 GPU 下载按钮禁用。不同显卡的速度、显存占用和省电情况需要实测，不保证固定加速倍数。

## CPU 翻译减负（2.0.17）

同一离线模型继续复用，不需要重新下载。CPU 推理关闭额外权重重排副本，控制计算批次；生成线程按逻辑 CPU 数的一半选择、最多 4，输入处理保留一个逻辑 CPU、最多 4，单核至少 1。Windows 尝试以较低优先级运行 CPU 工作进程，为桌面交互让出调度机会。GPU 参数和在线服务独立，不受这项 CPU 参数调整影响。

翻译结束、失败或取消后仍关闭模型进程，不以常驻大模型换取下一次启动速度。日志增加线程数、是否权重重排、累计 CPU 计算秒数等技术指标，不记录原文/译文。模型本身仍约 951 MB，完全离线推理不会变成只有几十 MB 的词典；实机速度取决于 CPU、内存和存储。

Windows CI 同轮样例中，原生峰值内存约减少 21%、耗时缩短约 11%，但累计 CPU 计算时间有所增加；本次主要减少内存，不能保证 CPU 总计算量或瞬时占用更低。详细对比及实际 4K 截图窗口记录见《2.0.17离线CPU翻译减负》。


## 2.0.21 开机自启、默认翻译方式与基础词典

主窗口 → “通用设置”：可开关“登录 Windows 后自动启动，常驻托盘”。默认关闭，开关即时保存，只设置当前用户的启动项，不需要管理员权限。便携版先放入固定文件夹，移动后需关闭再开启以更新路径。Windows 的“启动应用”若禁用了本软件，还需在系统中启用。重复自启动不会弹出已有实例提示或拉起主窗口。安装版卸载时，仅清理指向此安装目录的启动项。

文字工作台的方式下拉框包含“在线大模型”“离线模型”“基础词典（离线）”。选择后点击“保存为默认”，会保存方式与方向；新截图和重新启动软件均沿用。也可在“通用设置”中保存。单纯切换仅作用于当前窗口，点击保存后才改变默认值；保存不会发起翻译、连接服务器或加载模型。

在线服务失败时，原文和已有结果保留。切换“离线模型”或“基础词典”并保存，再翻译即可；以后不再反复请求原来失效的在线服务。保存在线服务地址/密钥只更新服务配置，不覆盖已保存的翻译方式。老版本已有的在线默认值在没有新设置时继续生效；新设置保存后优先使用新设置。

“基础词典”内置 ECDICT 常用词子集与少量界面词汇，2.0.22 已扩充到 100000 个不同词条（含 5000 条短语），资源约 5.4 MB。无需下载、不联网、不加载 Hy-MT2 或 CPU/GPU 推理器，只在查词时加载词典；中文反向查词索引在首次选择中译英查词时创建，英文查词不创建这一索引。提供英中词义、部分固定短语，以及常用中文词到英文词条的反向查词。结果按“词语 → 释义”显示；未知词标记“未收录”。这是一种基础查词方式，不进行整句翻译。单次上限 12000 字符、200 个不同词条；重复词不重复列出。

默认翻译方式存于 `%LOCALAPPDATA%\SelfSnip\translation-preferences.json`，不包含截图、识别文字或 API Key。开机自启使用当前用户的 `Software\Microsoft\Windows\CurrentVersion\Run` 中 `SelfSnip` 启动项，关闭只删除这一项。详细文件清单及验证见《2.0.21开机自启与默认翻译》。


## 2.0.22 十万词条基础词典

## 2.0.23 自动翻译方向、音标、词性与拼音

默认方向为“自动（中英互译）”：截图中的中文译成英文，英文译成中文。修改识别文字或粘贴新原文后，再次翻译会重新判断；在线、离线模型、基础词典都适用。界面显示当前判断以及译文实际使用的方向。中英混排按中文汉字数量与英文词数比较，以主要文字决定，相同时按中文处理；纯数字无语言特征时按英译中。特殊混合内容仍可手动选择方向。

升级时旧版保存的固定方向会切换为自动，原有在线 / 离线 / 基础词典方式保留。新版手动指定并保存的方向仍会在重启后保留。无需更换在线配置、密钥或重下离线模型。

选择“在线大模型”后，译文下方显示“读音与词性”：单词或短语提供美式国际音标（IPA）、词性（例如名词 n.、动词 v.）及中文释义；长句保留完整译文，并另列最多 8 个重点词。英文译成中文时，另外显示中文译文的带声调汉语拼音。中文译成英文时，词汇注释来自英文译文，不附中文拼音。窗口较小时可在译文区向下滚动查看注释；选中注释按 Ctrl+C 可复制，“复制译文”只复制译文正文。

译文、音标、词性和拼音由当前在线服务在同一次请求中返回，不额外下载发音组件、不自动请求其他平台。注释质量取决于所选模型；未提供完整注释时会提示并保留可用译文，错误格式、超时或取消时保留已有结果。基础词典及离线模型继续仅输出其原有结果，不生成在线语言注释。详细修改及验证见《2.0.23自动方向与在线语言注释》。


## 2.0.24 编辑响应与内存优化

优化连续画笔、贴纸移动 / 缩放和长图合成中的临时分配；没有文字输入时避免重复排版。整屏采集在后台运行，选择结束后释放整屏会话，再进入后续工作流。截图分辨率、标注输出及最多 100 步撤销保持一致。

诊断包的 `environment.json` → `Environment.Resources` 增加程序当时的物理工作集、私有提交、估计托管堆、累计 CPU 秒及 GC 次数。数据只在原有启动环境 / 导出诊断时读取，不持续后台采样或强制回收；离线模型子进程的峰值和退出状态见 `native-released` 日志。可分别在刚启动托盘、打开一张大截图、关闭编辑器后导出对比，关闭后不保证任务管理器数字立即归零，运行时 / WPF 可能保留可复用内存。

具体热点、修改文件、测试基准与实测结果见《2.0.24内存与交互性能分析》。在线服务等待和离线推理与编辑性能分别看，不将局部算法提速解释为所有流程都同比提速。

## 手动长截图响应优化（2.0.35）

手动拖选使用轻量边框并合并高频鼠标刷新，跳过可选滚动接口探测；松开后直接导出选区，减少额外的大图分配。操作仍是拖到网页下沿自动滚动、松开完成、Esc 取消。拼接质量判断和图片原始像素保留。修改与验证见 [2.0.35 手动长截图响应优化](2.0.35手动长截图响应优化.md)。

## 原文/译文中英朗读与原文状态记忆（2.0.36）

原文和译文都可点喇叭朗读，自动选择中文或英语 Windows 系统语音；在线、离线、基础查词和放大阅读窗口均可使用，再次点击停止，另一侧点击切换。无需大模型参与语音，缺少对应系统语音会提示添加。

点击“展开原文 / 收起原文”自动记住选择，新截图和重启后沿用；只识别文字时始终显示原文。状态独立保存，不更改默认翻译方式或保存截图文字。详见 [2.0.36 中英朗读与原文状态记忆](2.0.36中英朗读与原文状态记忆.md)。

## 在线 AI 发音（2.0.38）

“在线设置 → AI 语音设置 / 试听”提供 OpenAI、硅基流动、通义千问 TTS、MiniMax 及自定义配置，可填地址、模型、音色、密钥和播放速度，保存默认使用系统或在线语音。文字工作台“更多设置”也可切换并保存发音方式；与默认翻译方式分别保存。

仅点击喇叭时发送对应文字；试听使用固定短句，不自动保存草稿。支持同服务域名/地域的翻译密钥复用，独立密钥按 Windows 用户加密。失败时保留文字，由用户手动切回系统语音。详见 [2.0.38 在线 AI 语音](2.0.38在线AI语音.md)。
