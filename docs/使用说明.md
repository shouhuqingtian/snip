# 自用截图使用说明

## 安装和启动

适用于 Windows 10 22H2 / Windows 11 x64。便携版解压后运行 `Snip.exe`；安装版运行 `SelfSnip-1.0.0-Setup-x64.exe`。两者均已包含 .NET 运行时。

启动后图标出现在系统托盘，可能在“隐藏的图标”中。双击图标打开主窗口；右键菜单提供开始截图、打开主窗口和退出。关闭主窗口仅隐藏窗口，不退出。再次启动同一程序会激活已有实例。

当前发行包未代码签名，首次运行可能出现 Windows 发布者提示。请核对交付来源和 SHA256，不要关闭系统安全防护。

## 截图

1. 按 **Ctrl+Alt+A**，或通过托盘/主窗口开始截图。
2. 左键拖动框选区域，支持跨显示器。显示尺寸为截图实际像素尺寸，与屏幕缩放比例无关。
3. 松开后可拖动选区内部移动，拖动边缘/角点调整大小。
4. 按 **Enter** 或点击“编辑”进入编辑窗口；**Esc** 或右键取消。

快捷键无法注册时会出现提示。若微信等软件已占用 Ctrl+Alt+A，可通过托盘开始截图，或在其他软件中释放这个快捷键再重新启动本程序。

截图采集的是进入选区前的静态桌面。程序自身可见窗口会暂时隐藏。多显示器之间没有实际屏幕的空隙以黑色填充。显示器布局在选区期间改变时，当前截图取消并提示重试。

## 编辑

| 工具 | 操作 |
| --- | --- |
| 选择 | 点击标注选中，拖动移动，Delete 删除；双击文字重新编辑 |
| 矩形 / 椭圆 | 左键拖动绘制边框 |
| 箭头 | 从箭杆起点拖动到箭头终点 |
| 画笔 | 按住左键连续绘制，点击可绘制单个点 |
| 文字 | 点击放置位置，在对话框输入中文或多行文字并确认 |
| 马赛克 | 拖动矩形覆盖区域；块大小越大，像素化越明显 |

颜色提供常用选项，也可在输入框中填写 `#RRGGBB`。线宽、字号和马赛克块大小以原图像素为单位；这些设置作用于新标注，已存在的文字可通过双击修改颜色和字号。

编辑窗口底部提供缩放和“适应窗口”，超出窗口的画面可通过滚动条查看。缩放只影响显示，不改变导出分辨率。右键/Esc 取消正在绘制的标注。

马赛克会像素化当前已有画面（包括覆盖区域内此前的标注）。它是图片编辑效果，不作为彻底去除敏感信息的安全保证；后续添加的标注仍显示在它上方。

## 保存与复制

- **Ctrl+S / 保存 PNG**：选择路径，默认名称为 `自用截图_时间.png`。覆盖已有文件时会确认。
- **Ctrl+C / 复制**：将合成后的图片放到剪贴板，可粘贴到画图、文档或聊天窗口。
- **Ctrl+Z / Ctrl+Y**：撤销 / 重做，最多保留 100 步撤销历史。
- **Delete**：删除选中的标注。

导出包含全部已提交标注，不包含工具栏、选中边框和调整手柄。成功导出后编辑窗口保留。关闭有未导出修改的窗口会提示保存、放弃或取消；通过托盘退出也会检查编辑窗口。

## 已知边界

第一阶段不支持 OCR、AI、滚动截图、自动选择窗口、标注旋转/缩放、开机启动和自动更新。受保护的视频、DRM 内容、UAC 安全桌面或某些独占全屏应用可能无法通过标准桌面采集得到画面。

本阶段以 Windows 原生桌面为运行目标；具体实机验收状态见同仓库的验证记录。
