# 自用截图 2.0 系列使用说明

## 2.0.6 统一界面

主界面、选区工具栏、独立编辑器、文字识别/翻译、文字输入、贴纸、微信分享/诊断和贴图管理统一采用浅色卡片与绿色主操作。截图工具栏换为矢量图标，常用颜色可直接点击色点；自定义颜色仍可填写十六进制值。具体修改文件见《2.0.6界面美化》。下载页另有 `ui-previews.zip`，内含使用合成图片渲染的真实 Windows 窗口预览。

## 2.0.5 复制文字修复

“复制文字”和“复制译文”会显示正在复制、占用重试、复制成功或失败的独立提示。剪贴板短暂被其他软件占用时，约两秒内自动重试；等待期间窗口仍可操作。持续占用时保留截图和文字，稍后再点复制即可；也可在文字框中选中内容按 Ctrl+C。没有文字时复制按钮禁用。复制成功后关闭结果窗口或退出软件，文字仍保留在系统剪贴板。

诊断日志新增 `text-clipboard` 操作，记录成功、重试、失败和关闭取消；不记录原文或译文。修改文件和验证说明见《2.0.5复制文字修复》。

## 2.0.4 文字识别与离线翻译

截图后点击工具栏“文”或“译”，结束全屏选区并打开独立结果面板。左侧是截图预览，右侧是可修改和复制的识别文字；“译”会自动识别后翻译，保留原文和译文。关闭编辑窗口不会关闭识别结果。识别没有结果、缺少语言组件或翻译模型时，面板保留截图并说明原因；可以切换识别语言、重新识别、下载/修复模型后再次翻译。

2.0.4 修复结果窗口进度绑定导致整个软件退出的问题，并补充真实结果窗口和选区工具栏回归。运行日志是 `%LOCALAPPDATA%\SelfSnip\Logs\events.jsonl`；便携包里的 `validation/*.log` 属于构建检查记录，不会随使用更新。具体原因和修改文件见《2.0.4文字识别与翻译窗口修复》。

## 2.0.3 诊断与问题反馈

测试便携版在 GitHub Releases 的“测试便携版”条目下载，解压后运行 Snip.exe。先从托盘退出旧版，已有翻译模型可继续使用。版本和源码提交记录在 build-info.json 中；原生检查结果在 validation/validation-desktop.json，Passed/Failed/Unrun 分开记录。

遇到问题后，从主窗口点击 **导出诊断包…**，或右键托盘选择同名菜单，选一个位置保存 ZIP。反馈“进行了什么操作、出现什么现象”并附上诊断包，可减少反复询问系统信息。窗口无法操作时可重启应用后导出，轮转日志会保留近期记录。

诊断包包含软件完整版本、Windows/.NET、处理器数量、显示器尺寸/DPI、Chrome/Edge 安装版本、操作阶段、耗时及脱敏异常类型/HResult/堆栈。长截图另记录视口尺寸、滚轮单位、位移和重叠匹配误差。诊断不会自动上传，也不包含截图、OCR 原文、译文、网页地址、窗口标题、联系人、用户名或密钥。

日志存放于 `%LOCALAPPDATA%\SelfSnip\Logs`，后台写入，默认最多 5 个文件、每个 2 MiB。写入失败仍保留最近 200 条内存记录，导出文件会显示丢弃数和写入失败数。

也可使用命令行导出：

```powershell
./Snip.exe --export-diagnostics "$env:USERPROFILE\Desktop\自用截图-诊断.zip"
```

命令完成后退出（成功退出码 0），可用于自动验证或应用主界面无法打开时读取已有日志。导出的临时文件在失败/取消时清理，已有目标文件只在完整 ZIP 生成后替换。

## 启动与截图

运行于 Windows 10 22H2 / Windows 11 x64。便携版解压后运行 `Snip.exe`；安装版按当前用户安装。无需单独安装 .NET。首次启动部分原生组件会解压到用户临时目录。

软件常驻系统托盘，双击图标打开主窗口。按 **Ctrl+Alt+A** 或使用托盘开始截图；主窗口关闭后仍在托盘运行，退出使用托盘菜单。

进入截图后：鼠标悬停可预选窗口，单击选窗口，或左键拖动选择区域。选区支持多屏及不同缩放比例。松开鼠标后直接显示浮动工具栏并在选区内编辑。方向键在没有标注/文字输入时按实际像素微调选区。使用“重新调整选区”可移动边缘或拖动新区域，有标注时会先提示清除。

放大镜显示鼠标位置的原始画面细节；图片采集的是进入截图前的静态桌面。软件自身窗口会暂时隐藏；显示器间没有屏幕的区域为黑色。快捷键冲突、显示器布局改变会明确提示。

## 编辑工具栏

| 功能 | 操作 |
| --- | --- |
| 选择 ↖ | 点击标注选中，拖动移动；拖动标注边缘/角点缩放，Delete 删除 |
| 矩形 □ / 椭圆 ○ | 拖动绘制；可勾选填充，颜色和线宽作用于新标注 |
| 箭头 ↗ / 画笔 ✎ | 拖动绘制，画笔点击可画点 |
| 马赛克 ▦ | 拖动区域，块大小控制像素化程度 |
| 文字 T | 在图像位置输入，多行回车；Ctrl+Enter 或点击其他位置提交，Esc 取消当前文字；选择工具双击文字再编辑 |
| 表情 ☺ | 选择自绘通用表情或导入 PNG/JPEG 贴纸；移动、缩放、删除及撤销可用 |
| 文 | 打开离线 OCR 结果窗口 |
| 译 | 识别后翻译，或在结果窗口修正/输入原文再中英互译 |
| ↕ | 自动滚动长截图，当前支持有滚动接口的 Chrome/Edge 普通网页 |
| ↶ / ↷ | 撤销 / 重做，Ctrl+Z / Ctrl+Y，最多 100 步 |
| ↓ | 保存 PNG，Ctrl+S；选路径、覆盖确认，保存后保留编辑 |
| ⌖ | 将合成截图钉在桌面 |
| ➦ | 微信联系人搜索与发送流程，目标 4.1.15.12；尚待本机控件适配验证 |
| ▣ | 在独立编辑窗口中继续，保留当前标注 |
| ⌗ | 重新调整选区，确认后清除当前标注 |
| 红色 × | 取消截图，有未导出标注时确认 |
| 绿色 ✓ | 合成并复制到剪贴板、结束截图；复制失败时保留编辑 |

独立编辑窗口底部支持缩放/适应窗口，Ctrl+C 只复制并保留窗口，绿色对勾复制后关闭。颜色可填写 `#RRGGBB`，线宽/字号/马赛克以原图像素为单位。

PNG 和剪贴板输出不含工具栏、选择手柄或遮罩；缩放显示不改变原始像素尺寸。马赛克是像素化编辑效果，不是彻底删除敏感内容的安全保证。

## 贴图

贴图可拖动位置，滚轮缩放，右键复制、保存、调整透明度、开启鼠标穿透或关闭。Esc 关闭当前可交互贴图。

开启穿透后不能直接点击贴图；使用托盘“贴图管理”恢复交互或关闭。软件退出时关闭所有贴图。

## 离线 OCR 与翻译

OCR 使用 Windows 文字识别组件。选择中文或英语语言进行识别；未安装组件时软件提示安装。请在系统的语言/可选功能中补齐对应 OCR 组件。

翻译首次使用点击“下载 / 修复模型”，两个方向合计约 221 MB。模型下载源为 Hugging Face，版本和 SHA256 固定，下载完成后存放在 `%LOCALAPPDATA%\SelfSnip\Models`。安装/模型下载需要网络；模型齐备后识别与翻译在本机执行，不上传截图和原文。

OCR 原文可修正，翻译方向可选择英译中/中译英；原文和译文各有复制按钮。模型缺失、网络失败、取消或识别不到文字都有状态提示。通用机器翻译可能不够自然，请核对重要内容。单次翻译最多 12000 字符，内部按段落/分词长度分段。

第三方模型及组件许可见随包的 `THIRD-PARTY-NOTICES.txt`。

## 浏览器自动长截图

先在 Chrome/Edge 普通网页选择正文区域，至少 80×160 像素，不要把地址栏、工具栏放入选区；点 ↕。程序激活浏览器并自动向下滚动，采集重叠画面后拼接，完成时恢复原滚动位置并打开独立编辑窗口。

采集过程中不要切换窗口；Esc 取消。Chrome/Edge 使用原生滚轮采集，不要求提供辅助功能滚动接口；可用时会读取滚动位置用于校验。复杂嵌套列表、动态布局或真正无法确定移动距离时会明确停止。

上限为 90 秒、60 帧、24000 像素高或 6000 万像素；达到上限请分段截图。此功能仍需在你的浏览器实机验收。

## 微信发送与诊断

该入口要求微信 4.1.15.12 已登录，并提供可访问的界面控件。搜索联系人后选择明确目标，核对图片并点击发送；版本、目标、会话或图片预览不能核实时停止。同名目标需要改用唯一备注或完整微信号。

**当前尚未完成微信 4.1.15.12 实机控件适配，不能保证此入口在你的微信上可用。** 为补齐适配，可在便携目录的 PowerShell 运行：

```powershell
./Snip.exe --wechat-diagnostics
```

诊断工具只读取控件结构，不点击、搜索或发送；未知文字隐藏，AutomationId 不输出。保持微信窗口可见，点击读取后可保存脱敏 JSON。请提供输出或实际错误信息，以便继续适配。

## 2.0.1 网页截图与处理状态

先退出旧版托盘进程再更新。点击工具栏 ↕ 可选择整个网页、可见网页、选定区域或选区长截图。整个网页从顶部自动滚动至页尾；可见网页和选定区域不滚动。采集期间不要切换窗口，Esc 可取消。没有滚动位置接口时网页留在采集结束位置。

OCR 和翻译在后台处理，显示阶段、耗时和进度，可点击取消；OCR 超过 45 秒、翻译超过 90 秒会停止等待并保留已有结果。模型格式未变，已有翻译模型可继续使用。

## 2.0.2 采集界面

长截图期间会隐藏软件自身窗口和置顶贴图，采集结束后恢复；不再显示浮动进度窗。托盘提示显示采集状态。按 Esc 取消；打开托盘菜单也会先取消，避免菜单被拍进长图。白底文章、内嵌图片和固定底栏已增加专门的真实 Chrome 回归检查。


## 2.0.7 编辑性能

普通标注使用矢量预览，马赛克只计算对应小区域；未加标注的截图直接复用原图。关闭选区时清理编辑画布的事件订阅，并解除对旧选区窗口的引用，避免独立编辑器继续保留整张多屏桌面截图。

完全离线的中英翻译需要本地模型。Windows OCR 语言组件负责文字识别，并不提供通用中英翻译。当前仍使用已校验的量化翻译模型，不联网传输内容；无需重复下载已安装模型。性能优化详情和 Windows 对比记录见《2.0.7编辑性能优化》。
