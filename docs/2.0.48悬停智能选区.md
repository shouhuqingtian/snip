# 2.0.48 悬停智能选区

按截图快捷键后，完整窗口立即预选；后台进一步检测鼠标下的原生子窗口和辅助功能控件，尽量框选工具栏按钮、输入框、列表、行、面板等内部区域。直接 Enter 复制当前高亮区域，不要求先点击。手动拖选优先，进入标注或退出截图后停止检测并释放辅助进程。

检测不下载模型，不联网，不读取控件文字或名称，只通过内存管道传递句柄、进程标识和几何坐标。75 毫秒合并鼠标更新，同一会话仅一个检测任务；辅助进程首次请求最多 2.5 秒、后续 0.9 秒，内部另有 3 秒看门狗。失败回退完整窗口，本次截图不反复启动进程；迟到结果不能覆盖手动选区或已关闭的截图。

自绘画布、未公开辅助功能信息的网页或权限受限应用，可能只能识别网页正文或完整窗口；仍可拖选。内部区域识别以应用暴露的信息为基础，不保证任意网页 DOM 方块或每个 Excel 单元格都能自动识别。
