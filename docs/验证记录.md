## 打包工具调整

原定使用 Inno Setup。在隔离 Wine 环境中运行官方 Inno Setup 7 编译器安装程序时，该程序检查所需的 WOW64 支持，当前环境不具备其完整能力，未能完成安装。未修改或绕过包签名、校验值和 TLS 校验。最终使用支持 Linux 编译的 NSIS，保留当前用户安装、快捷方式和卸载行为。

隔离工具位于仓库之外的 `/workspace/.tools`，不属于产品源代码或发行包。后续 Windows 开发只需 README 中声明的 SDK、PowerShell 与 NSIS。
