# 2.0.72 语音输入的两种录音方式

“语音输入设置”增加“录音操作方式”：

- 按住说话，松开结束：保持 2.0.71 的行为。
- 按一次开始，再按一次结束：快速按下并松开快捷键后继续录音，再按同一个组合才结束录音并识别输入。

保存后立即生效，重新启动继续沿用；已有配置缺少方式字段时默认保持按住模式，不改变快捷键、服务或密钥。方式为本机全局语音偏好，不随服务选择变化。设置中的操作说明、保存反馈及录音状态提示均跟随所选方式。

两种方式都使用 Windows 默认麦克风，最长 2 分钟，Esc 取消；识别期间重复按快捷键不叠加录音。更改输入位置后保留结果供复制，确认的密码框不上传，自动输入不触碰剪贴板或发送消息。新方式不增加后台常驻麦克风、录音文件或自动上传。

## 修改文件

- `VoiceInput.cs`、`TranscriptionSettingsStore.cs`：录音方式、保存验证与旧配置兼容。
- `VoiceInputController.cs`：按住/再次按下的结束判断、准备期间停止、识别期间防重复、对应提示。
- `VoiceInputSettingsViewModel.cs`、设置 XAML、`VoiceInputStatusWindow.cs`、`App.xaml.cs`：模式选择与正确的操作说明。
- `WindowsMicrophoneRecorder.cs`、`VoiceWorkers.cs`：过短录音提示适用于两种方式。
- Core/Windows 检查：旧配置默认值、保存重开、真实快速按键开始/松开继续/再次按下结束、取消、输入位置保护、切回按住模式。
