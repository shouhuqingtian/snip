# 自用截图：第一阶段需求与设计（已确认并实施）

## 1. 项目目标

开发面向 Windows 的中文截图软件“自用截图”，采用 C#、WPF、.NET 8 和 MVVM 架构。参考微信截图的区域选择、遮罩和标注操作习惯，使用自主设计的浅色界面，不依赖微信进程或资源。

用户已确认本文范围并授权开发。实现与验收状态见功能变更记录和验证记录。

## 2. 已确认需求与实施默认值

用户已确认：完整基础标注（矩形、椭圆、箭头、画笔、文字、马赛克、颜色、线宽）；多显示器及不同缩放比例；托盘常驻；Ctrl+Alt+A；Esc 取消；快捷键冲突提示；剪贴板复制；PNG 保存；独立 EXE 和安装包。

以下采用实施默认值，用户可在确认本文时修改：

- 支持 Windows 10 22H2、Windows 11，首版面向 x64。
- 中文浅色界面；截图完成后打开独立编辑窗口。
- 单实例运行；再次启动时激活已有实例。
- 启动后进入托盘，托盘菜单提供“截图”“打开主窗口”“退出”；主窗口关闭时隐藏到托盘。
- 第一阶段不开机自启动、不上传截图、不需要账户或联网服务。
- 发布便携式、自包含单文件 EXE，以及按当前用户安装的安装包。目标 Windows 无需单独安装 .NET 8。
- 安装包使用 NSIS，提供开始菜单入口、可选桌面快捷方式及卸载功能；暂不包含自动更新。实现时因 Linux 兼容层缺少 Inno Setup 所需的 WOW64 支持，将打包工具从原定 Inno Setup 调整为 NSIS，交付行为保持本文约定。
- 软件名、主窗口标题和安装名称均为“自用截图”。

## 3. 操作流程

1. 用户通过 Ctrl+Alt+A、托盘菜单或主窗口“开始截图”触发截图。
2. 隐藏本软件可见窗口，等待画面刷新，采集所有显示器的静态画面，再显示选区遮罩，避免软件自身窗口和遮罩进入截图。
3. 遮罩覆盖多屏桌面；左键拖动选择区域，支持跨屏，显示选区实际像素尺寸。释放鼠标后可移动选区、拖动边缘或角点调整大小。
4. 点击“编辑”或按 Enter 确认选区；按 Esc 或右键取消。本阶段不包含自动识别窗口边界和滚动长截图。
5. 在独立编辑窗口添加标注，通过“复制”导出到剪贴板，或通过“保存”选择 PNG 路径。成功导出后保留编辑窗口，便于继续修改或再次导出。
6. 编辑窗口关闭且存在未导出的修改时，提示保存、放弃或取消。

## 4. 功能及验收标准

### 4.1 全局快捷键与托盘

- 使用 Windows RegisterHotKey 注册 Ctrl+Alt+A；应用不在前台时也能触发。
- 快捷键被占用时显示中文提示，软件仍可通过托盘和主窗口截图，不静默失败。
- 截图选择期间再次触发快捷键不重复创建会话；退出时释放快捷键、托盘图标及相关资源。
- 验收：其他应用处于前台时能进入截图；模拟快捷键冲突时显示提示；退出后快捷键可被其他进程注册。

### 4.2 屏幕区域截图

- 采用 Per-Monitor DPI Awareness V2；显式转换桌面物理像素与 WPF 逻辑坐标。
- 支持显示器位于主屏左侧或上方造成的负坐标；支持不同缩放比例及跨屏选区。
- 选区四周有遮罩，显示边框、调整手柄及实际像素宽高；禁止确认零尺寸选区。
- 导出采用源图像实际像素尺寸，窗口缩放不改变截图分辨率。
- 验收：单屏、双屏、100%/150% 混合缩放、负坐标及跨屏选区的内容和尺寸正确；Esc/右键取消后无残留遮罩。
- 显示器之间没有实际屏幕的桌面空隙填充为黑色；截图期间显示器布局变化则取消并提示重试。

### 4.3 截图编辑窗口

- 工具：选择、矩形、椭圆、箭头、画笔、文字、马赛克。
- 矩形、椭圆默认只绘制边框；箭头包含箭杆和箭头；画笔支持连续自由绘制。
- 文字工具点击画面创建文字，支持中文、多行、颜色及字号；文字提交后仍可重新编辑。
- 提供常用颜色及自定义颜色；线宽提供 2、4、6、8 像素，文字字号提供常用选项。
- 选择工具支持选中、移动、删除标注；第一阶段不要求标注旋转或拖动缩放。
- 马赛克通过拖动矩形区域形成像素化遮挡，提供不同块大小；导出后将效果合成到图片中。
- 支持撤销/重做，快捷键 Ctrl+Z/Ctrl+Y；一次绘制、移动、删除或文字提交作为一个操作。
- 编辑画面支持缩放和适应窗口；标注始终使用图片像素坐标，缩放只影响显示。
- 验收：每种工具可正常绘制并导出；移动、删除和撤销/重做结果正确；缩放后标注与截图内容保持对齐。

### 4.4 保存与复制

- 保存对话框默认文件名为“自用截图_yyyyMMdd_HHmmss.png”，允许用户选择路径，覆盖已有文件时确认。
- PNG 按原图像素尺寸合成全部已提交标注，不包含编辑工具栏、选择框或手柄。
- 剪贴板提供兼容常见 Windows 应用的图片格式；剪贴板被占用时有限重试，失败后显示中文提示。
- 文件无权限、路径不可用、磁盘写入失败等错误均提示用户，保留当前编辑内容。
- 验收：PNG 可被系统图片查看器打开；尺寸及标注正确；图片可粘贴到画图等应用；失败后可换路径重试。

### 4.5 基础 UI

- 主窗口：软件名称、开始截图按钮、快捷键说明、运行状态及版本信息。
- 托盘菜单：开始截图、打开主窗口、退出。
- 编辑窗口：工具栏、颜色与线宽/字号/马赛克设置、画布、撤销/重做、复制及保存按钮。
- 工具按钮提供中文提示、选中状态和可用状态；后台异常通过可理解的提示反馈。

## 5. 架构与目录

```text
src/
  Snip.Core/                 # 模型、编辑命令历史、服务接口与扩展契约
  Snip.Infrastructure/       # Win32、屏幕采集、导出、剪贴板、托盘等实现
  Snip.App/                  # WPF 入口、Views、ViewModels、资源及组合根
tests/
  Snip.Core.Tests/           # 坐标转换、选区及操作历史等核心测试
packaging/                   # 发布脚本、NSIS 配置
docs/                        # 使用、构建、验证与逐功能变更说明
```

- 核心模型不依赖窗口、托盘或具体 OCR/AI 供应商。
- ViewModel 管理状态及命令；View 的事件处理仅用于窗口、指针、焦点等 UI 适配。
- Windows 平台操作集中在服务中，采用依赖注入；优先使用 .NET/WPF/Win32 内置能力，第三方依赖只在必要时引入。
- 编辑文档保存原图及标注模型；预览与导出共享坐标和绘制规则，保证结果一致。
- 标注使用可撤销命令管理；截图会话明确区分空闲、选区、编辑和退出状态。
- 为 OCR 预留 IOcrService，为 AI 预留 IAiImageService，支持取消、异步调用和结果模型；第一阶段仅定义必要契约，不添加不可用按钮或虚假实现。
- 未来 OCR/AI 应由用户主动触发，联网、密钥及图片上传行为在对应阶段单独确认。
