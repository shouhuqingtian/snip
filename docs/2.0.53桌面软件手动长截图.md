# 2.0.53 桌面软件手动长截图

## 下载和操作

[Windows x64 安装包](https://github.com/shouhuqingtian/snip/releases/download/v2.0.53/SelfSnip-2.0.53-Setup-x64.exe) · [便携版](https://github.com/shouhuqingtian/snip/releases/download/v2.0.53/self-snip-2.0.53-win-x64.zip) · [完整源码](https://github.com/shouhuqingtian/snip/releases/download/v2.0.53/self-snip-source.zip) · [SHA256](https://github.com/shouhuqingtian/snip/releases/download/v2.0.53/SHA256SUMS.txt)

安装前先退出旧版托盘。按截图快捷键框选内容区，在长截图菜单选择“桌面软件手动长截图”，等待准备完成后分段向下滚动，点击完成或 Ctrl+Enter 生成长图。表格建议保留行号或有差异的内容，避免只选择相同的空白单元格；冻结表头、固定侧栏与滚动条尽量放在选区外。

## 边界

只进行纵向采集，不自动滚动、不自动获取整张工作表。重复列表、动态内容、冻结行列和嵌套滚动区可能使图像无法确定偏移；选择纯内容区并保留重叠，失败时不强行拼接。已采集部分可保存，界面会提示其不包含未可靠采集的尾段。限制为同一窗口、同一显示器，5 分钟、160 帧、24000 像素高和 6000 万像素，达到图像限制后保留已有结果。

公开 WPF 样例用于验证原生滚动与采集基础；不能将它们写成已实测用户安装的 Excel、WPS 或 ChatGPT 桌面版本。混合 DPI、具体应用的滚轮行为和虚拟化列表仍需实机验证。
