# 2.0.22 十万词条基础词典

## 行为和来源

基础词典从 12151 扩充到恰好 100000 个不同词条，其中 5000 条短语，保留全部旧词条。补充部分计算机、采购、财务等词语，固定来源、许可不变，用户无需另外下载。词义查询仍与整句翻译区分；未知词继续标明未收录。

生成脚本先保留原子集和常见应用用词，加入部分技术 / 业务词；扩充由常用词组成的短语，并按 BNC/词频、考试标签、音标及基础词形优先选择。没有频率区分的同层候选按固定词哈希排序，避免简单按字母表截取十万词。英文键大小写去重，维持常用词优先顺序供中文反向候选使用。

英文词表首次查词时加载；中文反向索引首次中英反向查询才创建。反向候选使用固定最多三个词的值结构，减少每个词义的列表分配；词性 / 领域前缀用字符切片处理。其他翻译方式不创建词典索引。不启动任何大模型推理进程。

- `packaging/BuildBasicDictionary.py`：可复现的十万词条筛选，固定上游 SHA256，5000 短语与旧词条保留。
- `src/Snip.Translation/Resources/basic-dictionary.json`：100000 个不同词条，5400790 字节，SHA256 `b2bb3a1943ea9304dfb51ac3f0c1003eb1c8f920494825141d16d6195a965a1b`。
- `src/Snip.Translation/BasicDictionaryTranslator.cs`：英文 / 中文索引分别按需初始化、精简反向候选存储、词条数检查。
- `src/Snip.App/ViewModels/TextResultViewModel.cs`：基础方式提示十万词条，原有模式保存与开机自启不变。
- `tests/Snip.Translation.Checks/BasicDictionaryChecks.cs`：扩展词 / 商业短语、数量去重 / SHA256、分方向冷查询耗时及托管数据内存上限检查。
- `tests/Snip.Translation.Checks/Program.cs`、`packaging/Validate.ps1`：单独词典检查入口，Linux 和真实 Windows 均检查。
- `Directory.Build.props`、`THIRD-PARTY-NOTICES.txt`、`docs/使用说明.md`、`README.md`：版本、数据来源及操作说明。
