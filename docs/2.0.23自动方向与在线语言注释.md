# 2.0.23 自动方向与在线语言注释

## 功能与修改文件

1. **自动中英方向**：每次翻译从本次原文快照判断，包括修改 OCR 结果后的再次翻译；对在线、离线模型和基础查词统一适用。中文汉字数量与英文单词数量比较，避免 API Key / Chrome 等长产品名使中文句子被判为英文；混排仍可手动覆盖。纯数字默认英译中。
   - `src/Snip.Core/TranslationDirection.cs`：平台无关的方向判断。
   - `src/Snip.Core/TranslationPreferences.cs`：默认 `auto`，保留两种显式方向。
   - `src/Snip.Infrastructure/TranslationPreferencesStore.cs`：旧设置读取时将旧方向迁移为自动，保留翻译方式；新文件 `SchemaVersion=2` 区分新版手动覆盖，仍采用临时文件原子替换。
   - `src/Snip.App/ViewModels/TextResultViewModel.cs`、`ApplicationSettingsViewModel.cs`、`src/Snip.App/Views/TextResultWindow.xaml`、`ApplicationSettingsWindow.xaml`：自动选项、当前判断和本次结果方向、默认保存与操作锁定。
2. **在线语言注释**：完整译文与注释分开；英文单词 / 短语显示美式 IPA、词性和中文词义，长句选最多 8 个重点词；中文译文附带声调拼音。复制译文只复制正文，注释可选中按 Ctrl+C。结果区可滚动查看。
   - `src/Snip.Core/AnnotatedTranslation.cs`：可选注释服务契约，保留旧纯文字翻译接口，离线服务无需实现注释。
   - `src/Snip.Translation/OnlineTranslator.cs`：一次文本请求返回译文和注释；原纯译文接口继续用于连接测试等调用。
   - `src/Snip.Translation/OnlineTranslationDetails.cs`：跨服务通用提示和有界解析，兼容 JSON 代码围栏；不完整的可选注释不丢弃译文，纯文本兼容响应提示缺少注释；错误结构不作为译文展示。词项去重、最多 8 条、限制字段长度 / 深度。沿用总响应 1 MiB、超时、取消及错误脱敏，不发送截图或自动切换平台。
   - `src/Snip.App/ViewModels/TextResultViewModel.cs`、`src/Snip.App/Views/TextResultWindow.xaml`：独立读音与词性区域，成功结果替换对应注释，失败 / 取消保留已有结果，不把上次注释混入新结果。
3. **回归与说明**：
   - `tests/Snip.Core.Tests/TranslationDirectionTests.cs`：纯中 / 英、混排、数字、扩展汉字、显式覆盖和默认设置。
   - `tests/Snip.Translation.Checks/OnlineTranslationChecks.cs`：六家预设 × 双方向注释协议、单次请求、注释上限、缺失 / 错误响应与取消；使用模拟 HTTP，不使用真实账号。
   - `tests/Snip.Windows.Checks/AutomaticTranslationChecks.cs`、`OnlineSettingsChecks.cs`：真实 WPF 窗口经模拟 HTTP 完成 OCR → 自动方向 → 修改原文 → 再翻译；复制正文、失败 / 取消保留、旧注释清除、离线及基础方向、诊断不含内容。
   - `tests/Snip.Windows.Checks/ApplicationSettingsChecks.cs`：旧设置各方式 / 方向迁移、新自动 / 手动方向重启保留、无效版本保护。
   - `tests/Snip.Windows.Checks/UiGalleryCheck.cs`：增加 3 张在线注释正常 / 紧凑尺寸预览，共 20 张。
   - `Directory.Build.props`、`docs/使用说明.md`、`README.md`：版本及使用 / 交付说明。
