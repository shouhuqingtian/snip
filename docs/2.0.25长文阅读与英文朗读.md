# 2.0.25 长文阅读与英文朗读

翻译工作台原有整页滚动、固定高度译文框及独立注释滚动区叠在一起，长文难以连贯阅读。本次把主要空间交给译文，并加入英文朗读。

## 使用方式

- 默认突出完整译文，译文框跟随窗口剩余空间伸展，主页面不再整体滚动。第一次翻译成功后折叠原文；点击“展开原文”仍可核对、编辑和复制，重新识别时自动展开。
- “完整译文”和“读音与词汇”分成页签。音标、词性和中文拼音保留在后者，不挤占译文，也不会混进“复制译文”的内容。没有注释时该页签不可用。
- 长文点击“放大阅读”，在独立窗口看完整内容并调整字号。复用当前结果，不重新请求服务，不重复解码截图或加载翻译模型；同一个工作台只打开一个阅读窗口。
- 在线模式将中文译成英文后出现喇叭“朗读英文”。点击播放，再次点击停止；关闭阅读窗口、关闭工作台、重新识别或翻译会停止当前朗读。保留结果不会因切换翻译方式而错误朗读其他语言。
- 发音使用 Windows 已安装的英语语音，与在线翻译服务无关，不额外发送文字、收费或下载翻译模型。未安装英语语音会提示在 Windows“时间和语言 → 语音”添加。音色自然度取决于系统语音；不是 DeepSeek/通义千问提供的在线音频。
- 常用操作留在主工具栏；识别语言、保存默认方式、离线计算和模型下载移至“更多设置”。原有默认方式保存和模型功能仍可使用。

## 资源与失败处理

语音服务构造时不访问原生语音组件，只有点击才创建合成器和播放器。长文按最多 600 个 UTF-16 字符分段合成播放，优先按句子或词边界切分，不拆开代理对；不会一次合成整篇音频。音频只留内存，完成或取消后释放，不建立常驻播放线程或音频文件缓存。

单次朗读最多 60000 字符、20 分钟；每段播放等待有上限。缺少语音、设备异常或取消时保留截图、原文、译文及窗口，语音提示独立于翻译状态。诊断只记阶段、字符数、语言和耗时，不记录朗读文字、原文、译文或原生错误消息。

## 验证过程中的回归修正

旧窗口位置检查仍查询已经移除的 WorkspaceScroll，其轮询回调异常被 Dispatcher 处理器接住，导致检查未退出。本轮改为检查最小窗口下原文、译文和关闭按钮可用，不再要求整页滚动；轮询会传播回调异常，窗口检查另有独立截止时间。新增只读的已保存日志检查工作流，今后可直接定位中断检查。工作台最小高度调为 640，翻译时展开原文最多占 90 DIP，并增加该状态的真实预览。
