# 2.0.39 窗口布局与手动长截图提速

## 窗口关闭操作

文字工作台、原文阅读、译文阅读、通用设置、在线识别与翻译设置、AI 语音设置统一使用底部的轻量关闭按钮，移除页标题旁的大号“关闭 Esc”。“关闭”和小键帽 Esc 分开呈现，按钮保持可点击、键盘焦点、悬停反馈及无障碍名称。原生标题栏的关闭按钮保留。Esc 仍关闭当前窗口，阅读窗口不会连带关闭文字工作台；关闭处理中窗口仍取消对应任务。

正常、低高度和窄窗口通过实际 WPF 渲染检查。关闭操作固定在可滚动内容之外，不需要滚到表单末尾才能退出。

## 手动长截图

原先无论网页视口多高，每次都只发送固定的一小格滚轮输入，每格又要等待画面稳定，长页面因此需要大量采集轮次。本次保留平滑滚动稳定检测，改为根据已经成功拼接的实际像素位移调整下一次滚轮步长：

- 持续拖到网页下沿时逐步加速，每次增长不超过两倍。
- 以扣除固定页头/页尾后的半个视口为目标，保留另一半供严格拼接校验。
- 根据实际位移适应 Windows 滚轮设置和不同视口尺寸，设置步长上限；移回网页内时停止继续滚动，再次靠边从保守步长开始。
- 松开鼠标完成；已发出的最后一次滚动必须稳定、拼接后，按最终选区裁剪，避免漏掉末尾或拍到动画中间态。

不放宽重叠匹配的误差或歧义阈值；遇到无法确认的内容仍提示而不拼出错误图片。选框与控制条仍排除在截图之外，自动截整页和从当前往下的策略保持原有流程。
