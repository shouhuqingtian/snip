增加后台语音输入：光标放到输入框，按住快捷键说话，松开后在线识别并输入文字。默认 Ctrl+Alt+Space，可在主窗口或托盘的“语音输入”里更改。

- 首次使用先配置并保存启用：支持硅基流动 SenseVoiceSmall、OpenAI 和自定义兼容语音识别接口，模型、地址和密钥可单独设置，也可显式复用同平台翻译密钥。语音输入无需下载离线翻译模型。
- 空闲时不打开麦克风。状态提示显示录音/识别进度，Esc 取消；不自动按回车发送，不覆盖剪贴板。输入位置改变或无法确认可编辑时保留结果，可从托盘查看并复制。
- 录音仅通过内存和匿名管道传输，密钥在本机加密保存。新增语音输入配置暂不进入账号同步或配置文件迁移，可复用已有的同步翻译密钥。

Windows 回归使用合成音频验证真实快捷键、WPF/Chrome 原生文字输入、焦点保护和录音辅助进程回收；未使用用户密钥或付费识别请求。实际麦克风权限、硬件和识别服务效果仍需在用户设备试用。特殊控件和管理员窗口可能需要手动复制识别结果。
